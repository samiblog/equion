# Equion Desk 도움말

Equion Desk는 Equion 프로젝트(자료 → 식 → 조립 → 과거 재현 → 전망 → 보고서)를 화면에서 다루는 앱입니다.
계산과 파일 형식은 모두 패키지 `equion`에 있고, 화면은 같은 명령을 부릅니다 — **화면에서 한 일은 터미널의 명령으로도 되고, 터미널(사람·Claude)이 한 일은
생기는 순간 화면에 뜹니다.**

## 화면

| 곳 | 무엇 |
|---|---|
| 왼쪽 위 | **작업대 줄** — 개요 · 자료 · 분석 실행 · 전망 · 보고서, 그리고 **지금 표본**(메뉴에서 바로 돌린 분석이 쓰는 구간) |
| 왼쪽 탭 | **변수**(시리즈 · 묶음) · **분석**(개별 식 · 돌린 분석) · **모형**(모형 · 블록과 식 · 가정 · 시나리오 · 스크립트) · **파일** · **기록**(결과 · 바뀜과 제안) |
| 가운데 | 작업대와 결과의 탭 — 닫았다 열면 지난 화면이 이어집니다 |
| 오른쪽 | **터미널**(다섯 개까지 — `[+]`로 더하기, Claude는 1번) · **명령 창**(Equion 명령 한 줄 — 위아래 자리를 바꾸고 경계를 끌어 높이를 바꿉니다) |
| 아래 | 작업 줄(지금 도는 계산과 취소) · 작업 기록 띠(새 기록이 한 줄씩) · 상태줄(지금 자료 회차) |

## 변수에서 시작하기

- 변수 탭에서 변수를 누르면 고르고, **Ctrl**로 더하고 **Shift**로 이어 고릅니다. 고른 차례가 번호로 보이고 아래 '고른 변수' 줄에서 끌어 바꿉니다
  (ECM은 첫 변수가 목표, VAR은 이 차례).
- **우클릭**(또는 '할 수 있는 일 ▾')하면 고른 수에 맞는 분석만 나옵니다 — 하나면 기술 통계 · 자기상관 · 단위근 …, 여럿이면 상관 · 그랜저 · 공적분 · VAR ….
  위에서 변환(수준 · 로그 · 차분 · 로그차분 · 전년비)을 고르면 대상이 `log(Y)`처럼 됩니다. 분석을 누르면 바로 돌고, '옵션'은 분석 실행 화면을 엽니다.
- 변수를 **두 번 누르면 변수 창**(차트 · 값 · 내력 · 분석), 여럿을 고르고 '그룹 창'이면 값 나란히 · 상관. 여럿을 '묶음으로 저장'하면 이름 하나로 씁니다.
- 계수표 · 전망 표 · 과거 재현 표의 변수 이름을 우클릭해도 같은 메뉴입니다.
- 모형에 넣지 않은 식은 **분석 탭의 개별 식**에 있습니다(식 작업대의 새 식 → '개별 식으로 남기기'). 마음에 들면 '모형에 넣기'로 모형이 쓰는 블록으로 옮깁니다.

## 혼자 하는 폼과 노트

- **후보 묶음** — 식 작업대의 '후보 묶음'. 종속 · 늘 넣을 것 · 고를 칸(`dlog(Y) | dlog(Y(-1))`처럼 `|`로)을 적으면 만들어질 식이 글자 그대로 보이고,
  '모두 추정'이 그 부품의 후보로 쌓습니다. '노트로 저장'은 그 줄들을 노트의 블록으로 남깁니다.
- **시나리오 폼** — 모형 탭의 '새 시나리오…'나 전망 화면의 '시나리오 ▾'. 충격 표(변수 · 크기 · % 또는 수준 · 처음 · 끝)와 식 보정을 적으면 바뀔 파일과 명령이
  바로 보이고, '저장하고 풀기'가 기준선과 함께 풉니다.
- **노트** — 분석 탭의 '노트'. 블록마다 상태(정상 · 낡음 · 실행 안 함)와 ▶ 실행, 머리에 '노트 전체 실행' · '낡은 것만'. 분석 결과와 카드의 '노트에'가 그 기록을
  노트에 담습니다 — 다음 회차에 노트를 다시 실행하면 됩니다.
- **이전과** — 분석 결과·카드의 '이전과'가 같은 분석·같은 대상의 앞 기록과 나란히 보이고, 판단이 바뀐 줄을 강조합니다.
- **요인 나누기** — 전망 화면에서 비교할 기록 하나를 고르고 '요인 나누기'. 보는 전망과의 연간 성장률 차이를 자료 → 가정 → 식 차례로 나눠, 무엇 때문에
  바뀌었는지 보입니다(분석 기록으로 남습니다).
- **시점이 열로 가는 표** — 불러오기 화면의 '시점 — 열로 감'과 시점 줄 · 이름 열. 통계 사이트의 표처럼 줄마다 시리즈 하나인 표를 그대로 읽습니다.
  머리줄이 여러 줄이면 '열 이름 줄'에 `3,4`처럼 적거나 줄 번호를 Shift+누릅니다 — 위 줄의 병합 칸을 이어 붙인 이름이 됩니다.
- **이정표** — 기록 탭의 '이정표'. 전망을 확정한 때처럼 중요한 때를 이름 붙여 남기고(정의 파일 · 자료 회차 · 고정한 기록), 지금과 견주고, 정의를 그때로 되돌립니다.
- **묶어 보내기 · 묶음 열기** — 개요의 '묶어 보내기'가 프로젝트를 zip 하나로(원자료는 고를 때만), 다른 PC의 첫 화면 '묶음 열기…'가 그것을 풀어 엽니다.

## 명령 창

`est demand:CN` · `an unitroot Y --trend ct` · `hs main`처럼 Equion 명령을 쳐서 Enter — 터미널과 같은 일이고 같은 기록이 남지만, 떠 있는 계산 프로세스가
바로 하므로 빠르고(0.1초 안팎) 결과의 탭이 가운데에 열립니다. `Tab` 자동 완성 · `↑↓` 지난 명령. 왼쪽에서 변수를 고르고 `an corr`처럼 분석 이름만 치면
고른 변수가 대상으로 들어갑니다. 파일을 바꾸는 명령도 바로 실행하고, 바뀐 것은 '바뀜 · 되돌리기' 칩으로 되돌립니다. Python 스크립트와 셸 명령은 터미널에서.

## 핵심 고리

1. **자료** — 받은 통계표(원자료)의 열을 시리즈로 짝짓고(불러오기), '자료 만들기'로 새 회차를 만들어 견준 뒤 '이 회차로 바꾸기'.
2. **식** — 모형 탭에서 식을 골라 식 작업대로. 식을 고쳐 `Ctrl+Enter`로 추정하면 후보가 쌓이고, 겹쳐 본 뒤 '채택'.
3. **모형** — 모형 작업대의 ① 조립(구성·연결·문제) → ② 과거 재현(풀기 → 오차 → 원인 따라가기) → ③ 전망.
4. **전망** — 가정 표에 값을 적고(엑셀에서 붙여 넣기) 기준선과 시나리오를 풉니다. 가정을 고쳐도 저절로 다시 풀지 않습니다.
5. **보고서** — 결과 화면의 '보고서로'가 표를 보고서의 한 구역으로 보냅니다. 다시 푼 뒤에는 보고서 탭의 '새 기록으로 바꾸기'가 그 구역만 바꿉니다.
6. **스크립트** — 달마다 하는 일을 `FLOWS/*.eqs`에 적어 흐름 화면에서 단계로 보며 실행합니다.

계산은 **단추를 누를 때만** 합니다. 계산할 때마다 `work/` 아래에 **기록**이 남고(`est:` 추정 · `hs:` 과거 재현 · `sim:` 전망 · `an:` 분석 · `run:` 실행),
기록은 고치지 않습니다 — 다시 계산하면 새 기록입니다.

## 고치는 것과 되돌리기

- **정의 파일**(블록 파일 · `equion.toml` · 자료 정의 · 가정 · 시나리오 · 보기 · 스크립트 · 노트 · 보고서)을 바꾸는 일은 무엇이 바뀌는지 먼저 보이고 저장합니다.
- 바뀔 때마다 **바뀜 기록**(위쪽의 시계 단추)에 누가 · 어떻게 · 전후 차이가 남습니다. 편집기나 Claude가 명령 없이 고친 것은 '바깥'으로 남습니다.
- 바뀜 기록에서 **되돌리기** — 그 바뀜 앞의 내용으로 다시 씁니다. 파일 여럿을 고친 바뀜은 파일 하나만 되돌릴 수도 있습니다. 되돌린 것도 기록에 남습니다.

## Claude와 함께

터미널에서 `claude`를 띄우면 Claude Code가 같은 폴더에서 같은 명령을 씁니다. 작업대와 결과 화면의 **Claude ▾** 가 요청 글을 터미널에 붙입니다
(Enter는 직접 누릅니다 — 앱이 대신 보내지 않습니다).

| 방식 | 무엇이 바뀌나 | 어디서 보나 |
|---|---|---|
| **맡기기** | Claude가 바로 파일을 고치고 명령으로 계산합니다 | 바뀜 알림과 바뀜 기록(되돌리기), 작업 기록 띠 |
| **제안 받기** | 아무것도 바뀌지 않습니다 — Claude가 제안만 남깁니다 | **제안** 탭: 바뀔 내용의 차이 · 까닭 · 미리 계산한 결과 → 적용 · 버림 |

처음 한 번 **Claude ▾ → Claude Code에 Equion 알려 주기**를 눌러 이 프로젝트에 Equion 스킬을 넣어 두면 Claude가 명령과 규칙을 압니다.
Claude가 `equion desk show <이름>`을 치면 그 기록·제안·식의 화면이 앞으로 옵니다.

Claude Code가 없어도 화면의 모든 기능은 그대로입니다.

## 같은 일을 하는 명령

화면마다 **명령 줄**(`> equion …`)이 있습니다 — 누르면 복사됩니다. 몇 가지:

```text
equion est demand:CN --sim            식을 추정하고 식만 따로 모의
equion adopt est:cn_0003              그 기록을 채택
equion hs main                        과거 재현
equion sim base oil20 --model main    기준선과 시나리오
equion report add 보고서 sim:…         결과를 보고서로
equion history list · revert h0007    바뀜 기록 · 되돌리기
equion propose list · apply p3        제안
equion run FLOWS/monthly.eqs          스크립트
equion an split "sim:a sim:b"         두 전망의 바뀜을 자료 · 가정 · 식으로
equion milestone make fc_2026_11      이정표 · bundle make 묶어 보내기
```

## 손버릇

| 키 | 하는 일 |
|---|---|
| `Ctrl+Enter` | 추정 · 풀기(식 작업대 · 분석 · 모형 · 전망) |
| `Ctrl+S` | 고치던 정의 파일 저장 |
| `Ctrl+W` | 가운데 탭 닫기 |
| `` Ctrl+` `` | 오른쪽 열(터미널 · 명령 창) 보이기 · 숨기기 |
| `Ctrl`·`Shift`+누르기 | 변수 여럿 고르기(변수 탭) |
| `F1` | 이 도움말 |

## 알아 둘 것

- 설정과 지난 화면은 사용자 폴더에 적습니다 — 프로젝트 폴더에는 설정을 두지 않습니다.
- 터미널의 색은 창의 바탕(밝게·어둡게)을 따릅니다. 밝은 바탕에서도 터미널만 어둡게 쓰려면 설정(톱니)의 '터미널 색'에서 '늘 어둡게'.
- 큰 모형의 계산은 몇 초가 걸립니다 — 작업 줄에 지난 시간과 '취소'가 보입니다.
- 터미널에서 `equion` 명령이 도는 중에 `Ctrl+C`를 누르면 '일괄 작업을 끝내시겠습니까 (Y/N)?'가 뜰 수 있습니다 — `Y`.
- 더 자세한 사용법은 패키지 문서(`docs/README.md`)와 `equion --help`, Claude용 안내는 `equion guide`.
