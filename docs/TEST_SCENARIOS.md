# 시험 시나리오 — 사용자의 관점 (2026-11-09)

지금까지의 시험(`tests/test_*.py`)은 기능마다 짠 것이다 — 명령 하나가 맞는 일을 하나. 이 문서는 **쓰는 사람의 관점**에서 다시 본다. 여러 달 운영하고,
사람과 Claude가 같은 폴더를 고치며, 일이 중간에 끊기고, 이상한 입력이 들어오고, 프로젝트가 다른 PC로 옮겨지고, 기록이 쌓였을 때다. 시나리오마다
**기대**를 먼저 적고, `tests/test_journeys.py`가 같은 번호(J1.1 …)로 확인한다. 자료는 예제 자료(`toy_q`·`toy_m`)를 코드로 바꾼 합성 표만 쓴다(D30).

| 묶음 | 관점 | 왜 |
|---|---|---|
| J1 | 한 해 운영 — 매달 새 원자료로 월간 스크립트 | 기능 시험은 한 달만 돌린다. 이름·회차·채택·재연이 달을 넘어 쌓일 때 깨지는 것은 거기서 안 보인다 |
| J2 | 사람과 Claude가 같은 폴더에서 | 명령 밖의 고침·낡은 제안·되돌리기가 기록과 맞물리는지 |
| J3 | 실패와 회복 | 망가진 파일·중간 실패·중단·깨진 설정에서 아무것도 반쯤 바뀌지 않고, 고친 뒤 이어서 할 수 있는지 |
| J4 | 적대적 입력 | 경로가 프로젝트 밖으로 나가거나, 값으로 명령을 바꾸거나, 셸 문자를 넣을 때 — 허용 목록·경로 가두기 |
| J5 | 이식성·재연 | 공백·한글 경로, 옮긴 폴더, 다른 판, Windows 줄바꿈 |
| J6 | 명령줄 사용성 | 모든 `--help`, `--json`, cp949 출력, 하위 폴더, 오류 메시지의 다음 할 일 |
| J7 | 규모 | 기록이 쌓였을 때 목록·검사가 느려지지 않는지 |

## J1. 한 해 운영 — 매달 새 원자료

사람: 매달 통계청 파일(여기서는 toy_q에 한 분기씩 더하고 지난 분기를 조금 고친 합성 파일 `toy_q_2020Q1.csv`, `toy_q_2020Q2.csv` …)을 받은 상자에 넣고
`equion run FLOWS/monthly.eqs`를 돌린다. 여섯 달.

| # | 기대 |
|---|---|
| J1.1 | 매달 받은 파일이 같은 출처(`na`)로 짝지어진다 — 파일 이름 끝의 기간(`_2020Q2`)이 바뀌어도. 여섯 번 모두 종료 코드 0 |
| J1.2 | 회차가 달마다 하나씩 늘고(처음 + 6), 달마다 그 회차 이름의 보고서와 엑셀이 생긴다. 자료 끝이 한 분기씩 밀린다 |
| J1.3 | 둘째 달의 실행을 여섯째 달 뒤에 재연해도 단계마다 같다(그 사이 원자료·정의·채택이 다 바뀌었어도) |
| J1.4 | `work clean --yes`(정리)를 해도 실행 기록이 가리키는 단계 기록은 지워지지 않아 재연이 계속 된다 |
| J1.5 | 채택표의 바뀜마다 그것을 바꾼 실행 이름이 남는다(누가 '스크립트') |
| J1.6 | 지난달 실행 기록에는 `work list`에서 '회차 다름'이 붙고, 이번 달 것에는 붙지 않는다 |

## J4. 적대적 입력

| # | 기대 |
|---|---|
| J4.1 | `report new ../../x`·절대 경로 → 거절(3), 프로젝트 밖에 파일이 생기지 않는다 |
| J4.2 | `note run <프로젝트 밖의 노트>` → 거절(3), 밖의 파일은 그대로 |
| J4.3 | 스크립트의 `run ../밖.eqs`·`py ../밖.py`·절대 경로 → 검사 문제(실행하지 않는다) |
| J4.4 | `--set` 값으로 선택지 끼워 넣기(`--set s="base --model core"`) → 거절. 음수 값(`-0.5`)은 된다 |
| J4.5 | 노트 블록의 셸 문자(`;`·`&&`·`$(…)`·`|`) → 셸로 돌지 않는다(그 블록은 오류, 파일은 그대로) |
| J4.6 | 기록·보고서·스크립트 이름의 경로 문자(`../`·`\`)·빈 이름 → 거절 |

## J6. 명령줄 사용성

| # | 기대 |
|---|---|
| J6.1 | 모든 명령과 하위 동작의 `--help`가 종료 코드 0 |
| J6.2 | `--json`을 받는 읽기 명령의 출력이 JSON으로 읽힌다 |
| J6.3 | 출력이 cp949(영문 Windows 파이프 등)여도 멈추지 않는다 — `✓`·`—` 같은 글자는 바꿔 쓴다 |
| J6.4 | 프로젝트의 하위 폴더에서 쳐도 프로젝트를 찾는다 |
| J6.5 | 흔한 오류(없는 부품·기록·모형·시나리오)마다 3과 다음 할 일(있는 이름·명령) |

| J6.7 | `--json`이 없으면 지금처럼 표준오류에 `equion: 오류: …` 한 줄(표준출력은 비어 있다) |
