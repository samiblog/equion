# 시험 시나리오 — 사용자의 관점 (2026-11-09)

지금까지의 시험(`tests/test_*.py`)은 기능마다 짠 것이다 — 명령 하나가 맞는 일을 하나. 이 문서는 **쓰는 사람의 관점**에서 다시 본다. 여러 달 운영하고,
사람과 Claude가 같은 폴더를 고치며, 일이 중간에 끊기고, 이상한 입력이 들어오고, 프로젝트가 다른 PC로 옮겨지고, 기록이 쌓였을 때다. 시나리오마다
**기대**를 먼저 적고, `tests/test_journeys.py`가 같은 번호(J1.1 …)로 확인한다. 자료는 예제 자료(`toy_q`·`toy_m`)를 코드로 바꾼 합성 표만 쓴다(D30).

## J10. 끊김과 동시 실행 (2026-11-13)

사람: `equion run FLOWS/monthly.eqs`가 도는 중 프로세스가 강제로 끝난다(작업 관리자의 '작업 끝내기' · Desk 창 닫기 — Windows는 TerminateProcess와
`taskkill /F /T`, 다른 OS는 SIGKILL — 정리할 틈이 없다). 끊는 때는 시각이 아니라 실행이 적는 상태(`work/run/.active/<이름>.json`)로 정한다 — 자료 단계
안(받은 파일을 넣는 언저리), 과거 재현 도중, 보고서 쓰기에 들어선 때. 그리고 다시 돌린다. 이어서 Claude Code가 명령을 나란히 돌리듯 같은 프로젝트에서
`adopt` 셋(같은 블록 파일의 다른 식 둘 + 다른 블록 하나)과 같은 부품의 `est` 넷을 프로세스마다 같은 순간에 띄운다(프로젝트 잠금 `work/.lock`).

## J11. 낯선 받은 파일 (2026-11-13)

사람: 원자료가 통계표처럼 단위 줄이 있는 `na.csv`(`unit_row = 2`)다. 다음 달 받은 파일의 모양이 조금씩 다르다 — 단위 줄이 빠졌다 · 열 이름 하나가

## J12. 풀리지 않는 모형 (2026-11-13)

사람: 수요 블록(모형 `core`)의 식을 바꿔 가며 풀어 본다 — 계수를 고정해 해가 없게 된 블록, 통계상 불일치를 두 번 적은 항등식, 선행변수, 해만 적은 구간.

| # | 기대 |
|---|---|
| J12.1 | 해가 없는 동시 블록(`CN c Y CN(-1) @coef 0 1 0` — CN = Y — 와 `Y = CN + I + G`) → `hs core`의 모든 기가 실패 대체(전에는 값이 1e18까지 커진 채 '정상')이고 까닭(자코비안 특이)을 말한다. 실패한 기는 실측으로 — 다음 기의 `Y(-1)`로 큰 값이 흐르지 않는다(Y = 실측, I의 RMSPE는 보통 크기) |
| J12.2 | 서로 종속인 항등식(`Y = CN + I + G + SD` · `SD = Y - CN - I - G`) → `assemble`이 문제 '서로 종속인 항등식 demand:Y · demand:SD'로 알리고(3) `hs`는 풀지 않는다(3) |
| J12.3 | 선행변수(`I c Y(+1) R`) → `sim`이 Fair-Taylor 모형 일관 기대로 풀고(정상 8 — 전에는 '실패 8'에 종료 코드 0) '알아서 한 것'과 기록(`mce`)에 적는다. `hs`는 선행 값에 실측(완전 예견)을 넣었다고 알린다 |
| J12.4 | 해만 적은 구간은 그 해의 마지막 기까지 — `est --smpl 2000:2019`는 2000Q1~2019Q4(n=80), `hs --range 2018:2019`는 2018Q1~2019Q4 |
