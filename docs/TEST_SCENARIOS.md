# 시험 시나리오 — 사용자의 관점 (2026-11-09)

지금까지의 시험(`tests/test_*.py`)은 기능마다 짠 것이다 — 명령 하나가 맞는 일을 하나. 이 문서는 **쓰는 사람의 관점**에서 다시 본다. 여러 달 운영하고,
사람과 Claude가 같은 폴더를 고치며, 일이 중간에 끊기고, 이상한 입력이 들어오고, 프로젝트가 다른 PC로 옮겨지고, 기록이 쌓였을 때다. 시나리오마다
**기대**를 먼저 적고, `tests/test_journeys.py`가 같은 번호(J1.1 …)로 확인한다. 자료는 예제 자료(`toy_q`·`toy_m`)를 코드로 바꾼 합성 표만 쓴다(D30).

`equion run FLOWS/monthly.eqs`를 돌린다. 여섯 달.
