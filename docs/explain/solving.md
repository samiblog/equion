# 연립 풀이

모델을 기간마다 어떻게 푸는지, 결측과 미수렴을 어떻게 다루는지, 결과의 상태가 무슨 뜻인지를 설명합니다.

## 한 번 읽고, 한 번 컴파일하고, 여러 번 푼다

1. **파서**가 식 글자를 허용 목록 문법으로 검사합니다(변수·숫자·사칙연산·지원 함수만 — 식이 코드를 실행할 수 없다).
2. 모든 시계열 연산(`log`·`dlog`·`.yoy`·`@movav`·시차 범위 …)을 **시차 잎의 산술식(IR)** 으로 펼칩니다.
   추정과 풀이가 같은 IR을 쓰므로 "실측을 넣은 모델의 잔차 = 추정 잔차"가 구조적으로 성립합니다.
3. **구조 분석**: 식마다 목표변수(좌변 첫 변수)를 정하고, 같은 기 의존 관계 그래프를 강하게 연결된 묶음(블록)으로 나눕니다
   (Tarjan 알고리즘). 블록은 위상 순서대로 풉니다 — 크기 1이면 순차, 2 이상이면 동시.
4. 블록마다 잔차 함수와 **해석적 자코비안**(IR을 기호 미분)을 파이썬 함수로 만들어 둡니다(변수 이름 대신 색인, builtins 없음).

```python
import equion as eqn

wf = eqn.datasets.load("toy_q")
m = wf.model("toy").merge("I c Y(-1) R", "CN c Y CN(-1)", "dlog(P) c dlog(Y) dlog(POIL)").append("Y = CN + I + G")
eqn.show(m.blocks())
```

## 블록 풀이

동시 블록은 Newton법(스케일링 + 라인서치)으로 풉니다. 수렴하지 않으면 `fallback` 순서(기본 hybr → lm → Gauss-Seidel)로 다시
시도합니다. 100변수 이상의 큰 블록은 희소 LU를 씁니다(`jacobian="auto"`). 수렴 기준은 **정규화 잔차**(식의 크기로 나눈 잔차)가
`tolerance`(기본 1e-10) 이하.

## 동적 · 정적 · fit

| `mode` | 내생변수 시차에 | 다른 같은 기 내생변수 | 보는 것 |
|---|---|---|---|
| `dynamic` | 지난 기의 **풀이 값** | 함께 푼다 | 모델 전체의 과거 재현·전망(오차 누적) |
| `static` | 실측 | 함께 푼다 | 한 기 앞 예측 |
| `fit` | 실측 | 실측 | 식 하나하나의 적합 |

## 결측과 실패 — 기간 상태

풀기 전에 식마다 입력(시차 포함)이 비었는지 봅니다. 그 뒤 블록을 풀고 기간마다 상태를 남깁니다.

| 상태 | 뜻 |
|---|---|
| `ok` | 모든 식이 풀렸다 |
| `partial` | 입력이 빈 식을 빼고 나머지를 풀었다(빠진 식의 목표변수 = 실측). 출력 `OK*` |
| `fallback` | 블록이 수렴하지 않아 실측으로 대신했다(`on_fail="actual"`) |
| `failed` | 값을 얻지 못했다(`on_fail="nan"`, 또는 모든 식이 빠지고 대신할 실측도 없음) |

정책: `on_missing="exclude"`(기본) · `"nan"` · `"stop"`, `on_fail="actual"`(기본) · `"keep"`(수렴 못 한 값 유지) · `"nan"` · `"stop"`.

**핵심 불변식: 실패한 해는 다음 기간의 시차로 흘러가지 않습니다.** 실패한 기간을 실측으로 대신하거나 비워 두므로, 한 기간의
문제가 뒤 기간 전체를 오염시키지 않습니다(엔진 v2에서 이 결함이 고용 과거 재현 오차를 1.8% → 45%로 키웠다).
적합도 통계는 실측으로 대신한 변수-기간을 빼고 계산합니다.

```python
r = m.solve("1970Q1", "1970Q3")
print(r.status()[["status", "excluded", "max_resid"]])
```

## 결정성과 재현

같은 자료·같은 식·같은 설정이면 같은 결과입니다(난수는 확률적 모의의 `seed`로만). 마지막 자리 수는 선형대수 라이브러리(BLAS)·
CPU에 따라 1e-12 수준에서 달라질 수 있어, 결과 비교는 허용오차로 합니다. 명령줄의 `--threads N`은 BLAS 스레드 수를 고정하고
manifest에 기록합니다.
