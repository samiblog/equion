# 시나리오와 전망

시나리오의 각 항목이 풀이에 무엇을 하는지, 별칭이 어떻게 붙는지, 기여도 분해가 무엇을 나누는지를 정리합니다.

## 시나리오 = 가정의 묶음, 결과 = 별칭 시리즈

모델에는 기준선 `baseline`(별칭 `_0`)이 있고, `m.scenario("이름")`이 새 시나리오(`_1`, `_2` …)를 만들어 **활성화**합니다.
`m.solve()`는 활성 시나리오로 풀어 내생변수 `X`의 결과를 `X` + 별칭(예: `Y_1`)으로 워크파일에 씁니다 — 실측 시리즈 `X`는 바뀌지 않습니다.
그래서 여러 가정의 결과를 나란히 두고 `m.compare("Y")`로 견줄 수 있습니다.

## 항목별로 하는 일

| 항목 | 풀이에서 | 쓰는 곳 |
|---|---|---|
| `override(외생, 경로)` | 외생변수의 값을 경로로 바꾼다(주지 않은 기간은 실측) | 전망 가정, 정책 경로 |
| `override(내생, 경로)` + `exclude` | 그 내생변수를 식 대신 경로로 고정 | 판단 반영, 외부 전망 끼워 넣기 |
| `override(내생, 경로)`만 | 풀이 구간 **밖**의 값(초기 시차)으로만 쓰인다 | 출발 조건 바꾸기 |
| `exclude(내생, s, e)` | 그 구간만 식 대신 실측 | 일부 변수만 실측으로 |
| `add_factor(식, 경로)` | 식 우변에 더한다(좌변 단위) | 판단 조정, 구조 변화 반영 |
| `init_add_factor(식, 기준시점)` | 기준시점 잔차를 이후 기간에 이어 붙인다 | 전망 출발점 맞추기(착지) |
| `use_residuals()` | 표본 안 추정 잔차를 모든 식에 | 과거 재현(모델 점검) |
| `shock(변수, 값, s, e, kind)` | 외생이면 경로를 더하기·%로, 추정식 목표변수면 조정항에 | 충격 분석 |
| `control(목표, 도구, 경로)` | 목표를 경로에 고정하고 도구(외생)를 함께 푼다 | 정책 역산 |

조정항은 **좌변 단위**입니다 — `log(CN) c …` 식에 0.01이면 소비를 약 1% 올립니다. 항등식 변수에는 조정항을 줄 수 없습니다.

## 목표 추적의 조건

목표 추적은 "목표의 식"을 도구에 대해 푸는 것이라, 같은 기에 도구에서 목표로 가는 경로가 있어야 합니다. 예제 모델에서 금리 `R`은
같은 기 투자 → 소득 → 물가로 이어지므로 물가를 목표로 금리를 풀 수 있지만, 정부지출 `G`로 같은 기 투자 `I`를 맞출 수는 없습니다
(`I`는 지난 기 소득에만 반응). 이때는 이유와 함께 오류로 알려 줍니다.

## 기여도 분해

시나리오의 항목들(외생 경로 하나하나, 충격, 조정항, exclude, 목표 추적)을 켜고 끄며 풀어 기준선과의 차이를 항목별로 나눕니다.

- **Shapley**(기본): 각 항목의 기여 = 그 항목을 넣는 모든 순서에서의 한계 효과의 평균. 2ⁿ번 풀며(항목 n ≤ 8), 기여의 합이 정확히
  전체 차이입니다(모델이 비선형이어도).
- **single**: 항목 하나씩 넣은 효과 + 나머지(상호작용). 항목이 많을 때.

```python
import equion as eqn

wf = eqn.datasets.load("toy_q")
m = wf.model("toy").merge("I c Y(-1) R", "CN c Y CN(-1)", "dlog(P) c dlog(Y) dlog(POIL)").append("Y = CN + I + G")
wf.smpl("2015Q1", "2015Q4")
m.solve()
m.scenario("mix").shock("G", 10, "2015Q1", "2015Q4").shock("R", -1, "2015Q1", "2015Q4")
m.solve()
t = m.decompose("Y", "mix").table("Y")
print(t.round(3))
```

## 전망

`m.forecast(s, e, exog_fill=…)`는 ① 필요하면 기간을 늘리고 ② 비어 있는 외생 경로를 규칙(`last`·`growth`·`trend`)으로 채운 뒤
③ 외생 경로와 시작 앞 내생변수 실측이 다 있는지 진단하고 ④ 풉니다. 진단에서 빈 것이 있으면 무엇이 언제 비었는지와 채우는 법을
알려 주고 멈춥니다.

## 확률적 모의와 승수

- **확률적 모의**(`m.stochastic`): 기간마다 추정 잔차 벡터(같은 날짜의 모든 식 잔차 — 식 사이 상관 보존)를 다시 뽑아 조정항으로 더해
  reps번 풉니다. `coef_uncertainty=True`면 계수도 N(b̂, Cov)에서 뽑습니다. 결과: 평균·표준편차·분위수 띠.
- **승수**(`m.multipliers`): 같은 조건의 기준선과 충격 풀이의 차이(수준·%). `permanent=False`면 첫 기간만 충격.
