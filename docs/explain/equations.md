# 방정식 문법

방정식(추정식·항등식·비선형 식)의 문법 전체. `wf.equation(…).ls("…")`에 넣는 글자, `model.merge("파일.txt")`가 읽는
방정식 파일, `wf.genr`·`wf.eval`의 식이 모두 같은 문법입니다. 예시의 변수 이름은 예제 자료(`toy_q` — 소비 CN·투자 I·정부지출 G·소득 Y·금리 R·RL·물가 P·유가 POIL·통화 M2)를 따르고,
끝의 [직접 해 보기](#직접-해-보기)는 그 자료로 실제로 돕니다.

EViews풍 텍스트를 적으면 엔진이 ① **파서**로 문법·안전성을 검증하고 ② 모든 시계열 연산을
**시차 잎의 산술식(IR)** 으로 전개해, 같은 IR로 **추정**과 **연립 풀이**를 모두 수행합니다.
그래서 "추정한 식"과 "푸는 식"이 항상 같은 의미를 가집니다. EViews 표기(`X(-1)`, `^`,
`@pc`, `@movav`, `d(x,n,s)` …)도 그대로 쓸 수 있습니다.

> 배우는 순서는 [튜토리얼 2: 방정식 추정](../tutorial/02-estimation.md), 함수·지시자 한눈에 보기는 [함수 목록](../reference/functions.md).

## 1. 기본 구조

방정식 파일은 **한 줄에 한 방정식**입니다. 분류 규칙은 하나입니다:

| 줄의 모양 | 종류 |
|----------|------|
| 최상위 `=` **없음** | **추정식** (EViews `ls` 명세) |
| 최상위 `=` 있음 + 계수 `c(n)` **없음** | **항등식** |
| 최상위 `=` 있음 + 계수 `c(n)` **있음** | **비선형(NLS) 추정식** — 줄 끝에 `@inst`가 있으면 **비선형 2단계 최소제곱(NL-TSLS)** |

등호 양옆 공백은 상관없습니다(`X=Y+Z` 도 항등식). 괄호 안의 `=`는 없습니다(문법상 불가).

### 1.1 추정 방정식 (Behavioral Equation)

```text
종속변수  c  독립변수1  독립변수2  ...
```

- `c` : 상수항(절편). **없으면 생략**합니다(상수항 없는 추정식도 정상 동작).
- 이 식이 결정하는 내생변수(목표변수)는 **좌변의 첫 변수**입니다(EViews 정규화 규칙).
  `log(W/P)` → `W`, `INV/Y` → `INV`, `dlog(EMP)` → `EMP`.

```text
log(CN) c log(Y-G/P) log(STK/P) log(CN(-1))
RL log(IB+I) RW+POIL.yoy R          # 상수항 c 없는 식도 OK
```

### 1.2 항등식 (Identity)

회계적으로 정의되는 식. 추정하지 않습니다. **좌변이 식이어도 됩니다**(목표변수 = 좌변 첫 변수).
우변에서도 시차·변화율·이동평균 등 모든 연산을 추정식과 똑같이 쓸 수 있습니다.

```text
Y = CN + I + G
ERATE = EMP/POP*100
log(XREAL) = log(XNOM/P)               # 좌변 식 → 목표 XREAL
XSTOCK = XSTOCK(-1) + XFLOW               # 시차 사용 가능
```

### 1.3 비선형 추정식 (NLS)

계수를 `c(1)`, `c(2)` … 로 직접 적고 `=`로 씁니다. 시작값은 `@start`(기본 0).

```text
CN = c(1) * Y^c(2)                         @start 1 1
log(CN) = c(1) + c(2)*log(Y) + c(3)*log(CN(-1))
```

줄 끝에 `@inst 도구…`를 더하면 같은 식을 비선형 2단계 최소제곱(NL-TSLS)으로 추정합니다([10. 추정법 지정](#10-추정법-지정)).
시스템(`wf.system`)에도 이런 식을 넣을 수 있습니다([레시피 R66](../howto/system-var.md#r66-비선형-시스템--계수-공유와-도구변수)).

```text
# 소비함수 — 전체 줄 주석

```

## 3. 변수·상수항·항 구분

- **변수명은 대소문자를 구분하지 않습니다.** 데이터 컬럼명과 철자만 같으면 실제 컬럼명으로
  자동 교정됩니다(`y`·`Y`, EViews 시차 `cn(-1)`도). 함수명(`LOG`)·
  상수항(`C`)·NLS 계수(`C(1)`)도 대소문자 무관. 철자가 틀리면 로드 시 오류로 알려줍니다.
- **숫자 상수**는 그대로: `R+100`, `log(RW+100)`. 전각문자는 자동 보정(`（→(`).
- **항 구분 규칙** (추정식):
  - **괄호 밖의 공백**만 항을 나눕니다. 괄호 안 공백은 자유입니다: `log(Y - G)`.
  - 단독 연산자 토큰은 앞뒤 토큰을 이어 **한 항**으로 만듭니다: `X1 + X2` → 한 설명변수.
  - 연산자로 끝나는 토큰은 다음 토큰과, `*`·`/`로 시작하는 토큰은 앞 토큰과 잇습니다.
  - `+`/`-`로 **시작**하는 토큰은 새 항(부호)입니다: `X -Y` → 두 항 `X`, `-Y`.
- ⚠ 함수명과 같은 이름의 변수(`LOG`·`EXP`·`ABS`·`SQRT`·`D`·`DLOG`)나 `C`라는 이름의 변수는
  쓸 수 없습니다(`C`는 상수항) — 식에 쓰면 분명한 오류, 그런 열이 든 파일은 열 때 경고합니다.

## 4. 시계열 연산자

변수나 괄호 묶음 뒤에 `.` 으로 붙입니다. **연쇄(체이닝) 가능**합니다.

| 표기 | 의미 | 전개(IR) |
|------|------|----------|
| `.t(-N)` = `(-N)` | N기 전 **시차** | `X(-N)` |
| `.t(N)` = `(N)` | N기 후 **선행**(lead) | `X(+N)` |
| `.qoq` | 전기 대비 변화율(%) | `(X/X(-1)-1)*100` (연간에서는 사용 불가 → `.yoy`) |
| `.yoy` | 전년 동기 대비 변화율(%) | `(X/X(-k)-1)*100`, k = 분기 4 · 월 12 · 연 1 |
| `.gr(N)` | N기 전 대비 변화율(%) | `(X/X(-N)-1)*100` |
| `.diff` | 1차 차분 | `X - X(-1)` |
| `.ma(N)` | N기 이동평균 | `(X + X(-1) + … + X(-(N-1)))/N` |

```text
CN.t(-1)   CN(-1)       # 둘 다 1분기 전 (EViews 표기 허용)
P.yoy                       # 전년동기비 (%)
CN.t(-4).ma(2)             # 체이닝
(P/POIL).ma(2)               # 괄호 묶음에 적용
log(Y).t(-1)             # 함수 결과의 시차 = log(Y(-1))
```

> 선행(lead)이 있는 식은 기본 모의에서 미래 실측을 읽습니다. 모형 일관(rational) 해가
> 필요하면 `simulate(..., mce=True)`(Fair-Taylor)를 쓰세요.

## 5. 수학 함수·변환 단축어·EViews 함수

| 표기 | 의미 |
|------|------|
| `log(X)` `exp(X)` `abs(X)` `sqrt(X)` | 자연로그·지수·절댓값·제곱근 (`@log` 등도 동일) |
| `X^2` = `X**2` | 거듭제곱 (EViews `^` 그대로 사용) |
| `d(X)` / `d(X, n)` / `d(X, n, s)` | 차분 / n차 차분 / n차 + 계절 s 차분 (EViews `d`) |
| `dlog(X)` / `dlog(X, n, s)` | 로그 차분 = `d(log(X), n, s)` |
| `@pc(X)` | 전기비 % = `100*(X/X(-1)-1)` |
| `@pch(X)` | 전기비 (비율) = `X/X(-1)-1` |
| `@pca(X)` | 연율화 전기비 % = `100*((X/X(-1))^k - 1)` (k=연간 시차) |
| `@pcy(X)` / `@pchy(X)` | 전년비 % / 비율 |
| `@movav(X, n)` / `@movsum(X, n)` | n기 이동평균 / 이동합 |

```text
dlog(P) c dlog(P(-1)) d(R) @pcy(POIL)
dlog(CN) c d(log(Y),1,4)           # 1차·계절(4) 차분
```

> 지원하지 않는 함수(`max`·`min`·`@iif` 등)는 어떤 함수가 지원되는지와 함께 오류로 알려줍니다.

## 6. 시차 범위

같은 변수에 여러 시차를 한꺼번에 넣습니다. 한 항의 범위가 **쓴 방향 순서대로 개별 항**으로
전개되어 각각 계수를 갖습니다. 구분자는 `to`, `:`, `..` 모두 허용합니다.

```text
log(PM) c log(PM.t(-1 to -2)) POIL.qoq
# → log(PM) c log(PM.t(-1)) log(PM.t(-2)) POIL.qoq
log(PM) c log(PM(-1 to -3))            # EViews 표기도 동일하게 전개
```

> 제약: **한 항에 시차 범위는 하나**만 사용하세요.

## 7. 더미·추세·계절 지시자

식 안에서 바로 선언하면 엔진이 컬럼을 자동 생성합니다. **시점 표기는 데이터 주기에 맞게**:
분기 `2008Q4` · 월 `2008M3`(또는 `2008-03`) · 연 `2008`. 데이터 기간을 늘리면(`extend`)
이 컬럼들은 자동으로 다시 계산됩니다.

| 지시자 | 생성 컬럼 | 의미 |
|--------|-----------|------|
| `@trend` | `TREND` | 선형 추세 (0,1,2,...) |
| `@d(2008Q4)` | `D_2008Q4` (월: `D_2008M03`) | **펄스** 더미 |
| `@d(2008Q4:2009Q1)` | `D_2008Q4_2009Q1` | **구간** 더미 |
| `@step(2020Q1)` | `STEP_2020Q1` | **계단** 더미 |
| `@seas` | 분기 `_Q2 _Q3 _Q4` / 월 `_M2…_M12` | **계절더미 집합**(아래) |
| `@seas(n)` | `_Qn` / `_Mn` | 특정 분기/월 단일 더미 |

### 7-1. 계절더미 `@seas`

인자 없는 `@seas`는 상수항 `c`가 있으면 **첫 분기(월)를 제외**(drop-first)해 더미 함정을 막습니다.
연간 데이터에서는 오류입니다(계절성 없음). 데이터가 이미 계절조정(SA)된 계열이면 대개
유의하지 않으니 필요할 때만 쓰세요.

```text
log(EMP) c log(EMP(-1)) @seas X.qoq      # 분기: _Q2 _Q3 _Q4
log(GC) c log(GC(-1)) @seas(2) @seas(3)         # 2·3분기만
```

## 9. 매크로 정의

`@def NAME = EXPR` 이후 줄에서 `NAME`이 `(EXPR)`로 치환됩니다(단어 경계 기준).

```text
@def REALRATE  = RL - P.yoy
log(I) c log(REALRATE+100) log(I(-1))
```

- 위에서 아래 순서로 적용되며 뒤 매크로가 앞 매크로를 쓸 수 있습니다.
- 매크로 이름은 데이터 변수명과 겹치지 않게 지으세요.

## 10. 추정법 지정

| 표기 | 추정법 | 설명 |
|------|--------|------|
| (없음) | OLS | 기본 |
| `@inst Z1 Z2 …` (또는 EViews식 단독 `@`) | **2SLS** | 도구변수. 식에 상수항이 있으면 도구에 자동 포함. 도구 수 ≥ 계수 수 |
| `@coef v1 v2 …` | **고정 계수** | 쓴 순서(‘c’ 위치 포함)대로 계수를 넣고 추정하지 않음 — 외부(EViews 등) 계수 이식 |
| `Y = … c(n) …` | **NLS** | 비선형 최소제곱. `@start v1 v2 …`로 시작값(c 번호 오름차순) |
| `Y = … c(n) … @inst Z1 Z2 …` | **NL-TSLS** | 비선형 2단계 최소제곱 — 잔차를 도구에 투영해 최소화. 도구에 상수항이 늘 들고, 도구 수 ≥ 계수 수. `@start`가 없으면 NLS 해에서 시작 |

```text
log(CN) c log(Y) log(CN(-1)) @inst log(Y(-1)) log(CN(-1)) log(POIL)
log(CN) c log(Y) log(CN(-1)) @coef 0.7 0.25 0.6          # c, log(Y), log(CN(-1)) 순
CN = c(1) * Y^c(2)  @start 1 1
CN = c(1) + c(2)*Y^c(3)  @start 10 0.5 1  @inst G R CN(-1) Y(-1)   # NL-TSLS
```

코드에서는 `Equation(..., method='tsls'|'nls'|'fixed', instruments=[...], coefficients=[...])`,
`eq.set_coefficients({...})`로도 지정할 수 있습니다. 워크파일에서는 같은 식 글자에 추정법 메서드를 고릅니다:
`.ls` · `.tsls` · `.nls` · `.fixed` · `.wls(weights=…)` · `.gmm(inst, weight=…)` · `.liml(inst)`([추정법 해설](estimation.md)).

### 10.1 AR(p) 오차항 — `ar(p)`

```text
log(CN) c log(Y) ar(1)            # uₜ = ρuₜ₋₁ + εₜ
log(CN) c log(Y) ar(1 to 2)       # AR(2) — ar(1) ar(2) 와 같음
```

선형 추정식에만(ls·fixed). 조건부 최소제곱으로 추정하고 계수 이름은 `AR(1)`…(Wald의 c(n) 번호는 쓴 항 다음).
풀이에서는 우변이 xₜb + Σρₚ(yₜ₋ₚ − xₜ₋ₚb)로 바뀌어 동적 풀이에서 오차가 이어집니다. `@coef`로 고정할 때는
AR 계수까지 쓴 순서대로 줍니다.

### 10.2 다항 분포시차 — `pdl(X, k, d[, 제약])`

```text
log(CN) c pdl(log(Y), 8, 3) log(CN(-1))       # 시차 0~8의 계수를 3차 다항식으로
log(CN) c pdl(log(Y), 8, 2, 3)                   # 제약: 1 가까운 끝(β₋₁=0)·2 먼 끝(β₉=0)·3 양 끝
```

계수 이름은 `PDL01`, `PDL02` …(식 전체에서 이어 번호). 시차별 계수 β₀…β_k와 합계는 `eq.lag_distribution()`.
X 자리에는 식(`log(X)`)도 됩니다. NLS(c(n) 꼴) 식 안에서는 쓰지 않습니다.

## 11. 자동 검증·보안

- **허용 목록 문법**: 변수·숫자·사칙연산·거듭제곱·지원 함수·`.t/.ma/.gr/.qoq/.yoy/.diff`만
  허용합니다. 그 밖의 구문(속성 접근 `__class__`, 첨자 `X[0]`, 문자열, 람다, 키워드 인자 …)은
  위치와 함께 거부됩니다. 방정식 텍스트로 코드를 실행할 수 없습니다.
- **미정의 변수(오타)**: 데이터에 없는 변수는 식 단위로 명확한 오류.
  예: `데이터에 없는 변수 ['CNN'] (오타이거나 데이터/지시자 누락)`
- **설명변수 계산 실패는 오류**: 과거처럼 그 항을 조용히 빼고 추정하지 않습니다.
- **중복 설명변수·상수항 중복·`@coef` 개수 불일치**: 오류.
- **모델 구조 검사**(풀이 전): 같은 변수를 결정하는 식이 둘 이상(중복 정의), 데이터에도 없고
  어떤 식도 결정하지 않는 변수, 식 수 ≠ 미지수 수, 구조적으로 풀 수 없는 시스템 → 오류.
- **입력 한도**(DECISIONS D18): 식 길이 20,000자 · 괄호 중첩 250 · 시차/선행 1,000 · 시차 범위 100 · 추정식 항 500.
  넘으면 계산을 시작하기 전에 바로 오류 — 극단 입력이 메모리·시간을 다 쓰지 못하게.

## 12. 조정항 add-factor와 시나리오

방정식 파일 문법이 아니라 **실행 옵션**입니다([시나리오와 전망 해설](scenarios.md)).

<!-- skip -->
```python
m.scenario("replay").use_residuals()                         # 표본 내 잔차를 조정항으로(과거 재현)
m.scenario("adj").add_factor("log(CN)", {"2023Q1": 0.01})  # 수동(좌변 단위 — 로그 단위)
m.scenario("landed").init_add_factor("P", "2022Q4")         # 기준 시점 잔차를 이어 붙인다
```

- 조정항은 **좌변 단위**로 우변에 더해집니다(`log(CN)` 식이면 로그 단위).
- 표본 잔차를 모두 더해도 실측이 완전히 재현되지 않으면 데이터에서 성립하지 않는 항등식이
  있다는 뜻입니다(예: 국민소득 항등식에서 구성 항목 하나를 빠뜨린 경우).

## 14. 자주 하는 실수와 팁

1. **괄호 균형** — `log(P.t(-1)` ❌ → 위치와 함께 오류.
2. **항등식인데 계수 `c(n)`을 썼다** — NLS 추정식으로 분류됩니다. 항등식에는 `c(n)`을 쓰지 마세요.
3. **상수 가산 범위는 괄호로** — `(P.yoy+100).ma(4)`처럼 의도한 범위를 묶으세요.
4. **시차 범위는 한 항에 하나만.**
5. **매크로/변수 이름 충돌 주의** — 겹치면 변수가 정의식으로 치환됩니다.
6. **계절조정 계열에 `@seas`** — 대개 불필요(유의하지 않음).
7. **단위 확인** — 지수(2020=100)로 나눌 때는 `/ (P/100)`처럼 기준을 맞추세요
   (`G/P`는 실질 금액의 1/100이 됩니다).

## 15. 전체 문법 치트시트

```text
─ 구조 ────────────────────────────────────────────────
추정식 :  종속변수 c 독립변수 ...          (최상위 = 없음, c는 선택)
항등식 :  좌변식 = 우변식                  (= 있고 c(n) 없음, 공백 무관)
NLS    :  좌변식 = …c(1)…c(2)…  @start …   (= 와 c(n))
주석   :  # 이후 끝까지

─ 시계열 (체이닝 가능) ─────────────────────────────────
.t(-N) = (-N) 시차   .t(N) = (N) 선행
.qoq 전기비%   .yoy 전년비%(Q4/M12/A1)   .gr(N) N기비%   .diff 차분   .ma(N) 이동평균

─ 함수 ────────────────────────────────────────────────
log exp abs sqrt   ^ (=**)   d(X[,n[,s]])   dlog(X[,n[,s]])
@pc @pch @pca @pcy @pchy   @movav(X,n) @movsum(X,n)   @log @exp @abs @sqrt

─ 시차 범위 ───────────────────────────────────────────
.t(-1 to -3)   X(-1 to -3)   .t(-1:-3)   .t(-2..-4)

─ 지시자 (자동 컬럼, 주기별 시점 표기) ─────────────────
@trend   @d(P)   @d(P1:P2)   @step(P)   @seas   @seas(n)

─ 줄 단위 지시 ────────────────────────────────────────
@smpl S E      @def NAME = EXPR
@inst Z1 Z2 (또는 @ Z1 Z2)   @coef v1 v2 …   @start v1 v2 …

─ 특수 항 (선형 추정식) ───────────────────────────────
ar(1) ar(2)  ar(1 to 4)          AR(p) 오차
pdl(X, k, d[, 1|2|3])            다항 분포시차(제약: 가까운 끝·먼 끝·양 끝)

─ 실행 옵션 (코드) ────────────────────────────────────
m.solve(mode='dynamic'|'static'|'fit', mce=True, mce_method='fair-taylor'|'stacked', jacobian='auto'|'dense'|'sparse')
m.scenario("이름").override/exclude/add_factor/init_add_factor/shock/control/use_residuals
```
