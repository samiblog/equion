# 추정법

Equion의 추정법이 무엇을 계산하는지, 어떤 가정에서 맞는지, 언제 쓰는지를 정리합니다. 모든 계산은 패키지 안에서 직접 하고
(외부 회귀 패키지 없음), 기준 구현과의 비교는 [검증 보고서](validation.md)에 있습니다.

표기: 관측치 n, 계수 k, 종속변수 y(n), 회귀변수 X(n×k), 도구변수 Z(n×m), 잔차 e = y − Xb.

## 최소제곱(OLS) — `ls`

b = argmin ‖y − Xb‖². 정규방정식 대신 X의 특잇값 분해로 유사역행렬을 만들어 풉니다 — 조건수가 제곱되지 않고, 완전 공선이어도
(최소 노름 해를 내고 **경고**합니다) 멈추지 않습니다.

- 보통 공분산: s²(XᵀX)⁻¹, s² = e'e/(n − k)
- R²는 상수항이 있으면 중심화(1 − SSR/Σ(y − ȳ)²), 없으면 비중심 값을 `r_squared_uncentered`로 따로 줍니다.
- 가정: 설명변수가 오차와 상관하지 않는다(외생성). 이 가정이 깨지면(동시성·측정오차·빠진 변수) 치우칩니다.

## 강건 공분산 — `cov="white"`, `cov="hac"`

계수는 그대로, 표준오차만 바꿉니다. 샌드위치 (XᵀX)⁻¹ (Σ eₜ² xₜxₜᵀ) (XᵀX)⁻¹ 꼴.

| `cov` | 무엇에 강건한가 | 비고 |
|---|---|---|
| `hc0` | 이분산 | White(1980) 원형 |
| `hc1` = `white` | 이분산 | n/(n − k) 보정 — 보통 이것 |
| `hc2` · `hc3` | 이분산 | 지렛값 보정(작은 표본에 hc3) |
| `hac` | 이분산 + 자기상관 | Newey-West(Bartlett 가중), 시차 기본 ⌊4(n/100)^(2/9)⌋ |

## 가중 최소제곱(WLS) — `wls`

Σ wₜeₜ²를 최소화(w ∝ 1/분산). √w를 곱한 자료에 OLS와 같은 계산을 합니다. `resid`·`fitted`는 가중 전 값(연립 풀이에서 쓰는 것과 같은
뜻)이고, R²·SSR·DW는 가중 잔차로, 가중 전 값은 `stats["unweighted_*"]`로 줍니다.

## 도구변수 — 2SLS(`tsls`) · GMM(`gmm`) · LIML(`liml`)

설명변수 일부가 오차와 상관할 때(예: 소비식의 같은 기 소득), 오차와 무관하고 그 변수와 상관하는 **도구변수** Z를 씁니다.

- **2SLS**: X̂ = Z(ZᵀZ)⁻¹ZᵀX로 투영한 뒤 y를 X̂에 회귀. 두 단계 모두 유사역행렬로. 도구 수 m ≥ 계수 수 k(식별 조건).
- **GMM**: 모멘트 E[zₜ(yₜ − xₜb)] = 0. 1단계 2SLS 잔차로 가중행렬 W = S⁻¹(이분산 강건 `white` 또는 `hac`)을 만들어 다시 추정.
  과대식별(m > k)이면 Hansen J 통계량 n·ḡᵀWḡ(자유도 m − k)로 도구의 타당성을 검정합니다 — p값이 작으면 도구 일부가 오차와 상관.
- **LIML**: k-class 추정량 b = [Xᵀ(I − κM_Z)X]⁻¹Xᵀ(I − κM_Z)y, κ는 최소 고윳값. 도구가 약할 때(1단계 설명력이 낮을 때) 2SLS보다
  덜 치우칩니다. κ = 1이면 2SLS와 같습니다.

```python
import equion as eqn

wf = eqn.datasets.load("toy_q")
eqn.verbose(0)
inst = " @inst G R CN(-1) Y(-1)"
for name, fn in (("ols", "ls"), ("tsls", "tsls"), ("gmm", "gmm"), ("liml", "liml")):
    spec = "CN c Y CN(-1)" + ("" if fn == "ls" else inst)
    e = getattr(wf.equation("cn_" + name), fn)(spec)
    print(f"{name:5s}", e.coefs.round(3).tolist(), e.stderrs.round(3).tolist())
eqn.verbose(1)
```

## 비선형 최소제곱(NLS) — `ls("Y = c(1) + …")`, `nls`

계수 c(n)에 비선형인 식. 기울기 ∂f/∂c는 식을 기호 미분해 정확히 계산하고(수치 미분이 아님), Gauss-Newton 계열로 풉니다.
선형 식을 NLS로 쓰면 OLS와 소수 14자리까지 같습니다. 시작값이 나쁘면 국소 해에 머물 수 있어 `@start`로 그럴듯한 값을 줍니다.

## AR(p) 오차 — `ar(1)`

yₜ = xₜb + uₜ, uₜ = ρuₜ₋₁ + εₜ. ρ를 넣어 준차분한 식 yₜ − ρyₜ₋₁ = (xₜ − ρxₜ₋₁)b + εₜ를 비선형 최소제곱으로 풉니다.
조건부 최소제곱의 목적함수는 ρ에 대해 국소 최소가 여럿일 수 있어, ρ를 넓게 훑어 전역 최소를 고릅니다(결과에 알린다 — D21).
연립 풀이에서도 같은 식(준차분 꼴)으로 쓰입니다.

## 다항 분포시차(PDL) — `pdl(X, k, d[, 끝점])`

시차 0…k의 계수 βⱼ를 d차 다항식 βⱼ = Σ αᵢ jⁱ로 묶어 추정합니다(계수 k + 1개 → d + 1개). 끝점 제약: 1 가까운 끝(β₋₁ = 0),
2 먼 끝(β_{k+1} = 0), 3 양 끝. `lag_distribution()`이 βⱼ와 그 표준오차·합계를 보여 줍니다.

## 고정 계수 — `fixed`

다른 곳에서 얻은 계수를 그대로 씁니다. 표준오차는 없고 적합도(R² 등)만 계산합니다. 모델·시나리오에서 추정식처럼 쓰입니다.

## 시스템 추정 — `wf.system`

| 방법 | 무엇을 | 가정 |
|---|---|---|
| `ols` | 식마다 최소제곱(공유 계수·제약 반영) | 외생 설명변수 |
| `sur` | OLS 잔차의 Σ̂로 GLS(`iterate=True` = 정규 최우) | 외생 설명변수, 식 사이 오차 상관 |
| `tsls` | 식마다 2SLS | 도구변수 |
| `three_sls` | 2SLS 잔차의 Σ̂로 GLS | 도구변수, 식 사이 오차 상관 |
| `fiml` | 집중 로그우도 최대화 | 모든 같은 기 내생변수가 시스템 식의 목표변수 |

식 사이 제약은 같은 `c(n)`을 쓰거나 `restrict=["c(2) = c(5)"]`로. FIML은 항등식을 시스템에 넣을 수 없으므로 항등식이 정하는
내생변수(Klein 모형의 이윤 등)가 설명변수에 있으면 외생으로 다룹니다 — 그런 모형은 3SLS를 씁니다(경고가 나온다).

## VAR·VECM

- **VAR(p)**: yₜ = c + Σᵢ Aᵢyₜ₋ᵢ + εₜ를 식마다 OLS. 충격반응은 촐레스키 분해(변수 순서가 같은 기의 인과 순서), 분산분해는 h기
  예측오차 분산을 충격별로 나눈 것, Granger 인과는 한 변수의 모든 시차가 0인지의 Wald F.
- **VECM**: Δyₜ = α(β'yₜ₋₁ + 관계 안 결정항) + Σ ΓᵢΔyₜ₋ᵢ + 관계 밖 결정항 + εₜ를 Johansen 축소 순위 회귀(최우)로. β는 위 r×r을
  단위행렬로 정규화합니다. 순위는 `wf.johansen`의 트레이스·최대 고유값 검정으로 고릅니다.

## 어떤 방법을 쓸까

| 상황 | 방법 |
|---|---|
| 설명변수가 외생, 오차가 고른 | OLS(`ls`) |
| 잔차에 이분산·자기상관 | OLS + `cov="white"`·`"hac"`, 자기상관이 모형의 일부면 `ar(1)` |
| 같은 기 내생변수가 설명변수 | `tsls`(도구가 약하면 `liml`, 이분산이면 `gmm`) |
| 여러 식의 오차가 상관 | `wf.system` → `sur`(외생) · `three_sls`(내생) |
| 시차가 긴 반응 | `pdl` |
| 공적분 관계 | `wf.ecm`(한 식) · `wf.vecm`(여러 변수) |
