# Equion Desk 시험판(D0) 점검표

시험판의 목적은 화면이 아니라 **두 가지 위험**을 확인하는 것이다 — ① 식을 고치고 추정 결과를 보기까지 1초 안(성공 기준 S1), ② 설치 파일 하나로
어떤 PC에서든 똑같이 돈다(S10). 넘지 못하면 런타임 방식을 다시 고른다(DECISIONS D39). 계획은 [`DESK_DEVPLAN.md`](DESK_DEVPLAN.md).

## 설치 파일 만들기

저장소에서(Windows, Inno Setup 6 필요 — 인터넷은 만들 때만):

    uv run python desk/build/make.py

`desk/dist/EquionDesk-0.1.0.dev0-setup.exe`(47MB)가 생긴다. 설치 파일은 저장소에 넣지 않는다 — 다른 PC에는 이 파일만 옮긴다.
서명이 없어 처음 실행할 때 Windows SmartScreen이 "PC 보호" 창을 띄운다 — '추가 정보' → '실행'.

## PC마다 할 일 (5분)

| # | 할 일 | 기대 |
|---|---|---|
| 1 | 설치 파일 실행 — 관리자 권한을 묻지 않아야 한다 | 설치 20초 안팎, `%LOCALAPPDATA%\Programs\EquionDesk`(242MB) |
| 2 | 시작 메뉴의 **Equion Desk** 실행 | 창이 뜨고 '프로젝트 열기' 화면 |
| 3 | **예제 프로젝트 만들기** | 문서 폴더의 `Equion\example1`이 열리고 왼쪽에 부품 여섯 개, 머리줄에 '작업 프로세스 준비됨' |
| 4 | 왼쪽에서 `demand:CN` 누르기 | 계수표·진단·차트. '누른 뒤 화면까지'가 **1초 안**(개발 PC 0.06초) |
| 5 | 식 칸에 `CN c Y CN(-1) CN(-2)`를 쓰고 Ctrl+Enter | 항이 넷인 결과 |
| 6 | **과거 재현** · **전망(base)** 누르기 | 왼쪽 아래에 `hs:…`·`sim:…` 기록 이름과 걸린 시간 |
| 7 | 오른쪽 터미널에서 `python -c "import sys; print(sys.executable)"` | 설치 폴더의 `runtime\python.exe` — PC의 다른 Python이 아니다 |
| 8 | 터미널에서 `equion --version` · `equion est demand:CN` | 판 번호 · 추정 결과 글 |
| 9 | (Claude Code가 있으면) 터미널에서 `claude` | Claude Code가 뜬다 — 없으면 건너뛴다 |
| 10 | 창을 닫고 '앱 및 기능'에서 Equion Desk 제거 | 설치 폴더가 사라진다(문서 폴더의 예제는 남는다) |

어긋난 곳은 번호와 화면에 보인 글(또는 화면 그림)을 적어 주면 된다. 창이 아예 뜨지 않으면 명령 프롬프트에서
`"%LOCALAPPDATA%\Programs\EquionDesk\runtime\python.exe" -I -m equion_desk --browser`를 돌려 나오는 글을 적는다.

## PC 여덟 가지

| # | PC | 상태 (2026-11-11) |
|---|---|---|
| ① | Python이 없는 PC | 확인 못 함 — 다른 PC 필요 |
| ② | Python 3.9·3.15가 있는 PC | **통과**(개발 PC — 3.15가 있다): 터미널·작업 프로세스가 설치본의 3.13을 쓴다 |
| ③ | Anaconda가 있는 PC | 일부 — 개발 PC에 지워진 Anaconda의 레지스트리 항목이 남아 있고 영향이 없다. Anaconda가 살아 있는 PC는 확인 못 함 |
| ④ | `PYTHONPATH`·`PYTHONHOME`이 설정된 PC | **통과**(개발 PC에서 변수를 일부러 틀리게 주고 — 같은 이름의 가짜 `numpy`까지 두고 — 실행): 앱·작업 프로세스·터미널이 읽지 않는다. 자동 시험 D13·E3·E4 |
| ⑤ | 깨진 바로 가기가 남은 PC(지워진 Python을 가리키는 chocolatey 바로 가기) | **통과**(개발 PC가 그렇다) |
| ⑥ | 인터넷이 없는 PC | 확인 못 함 — 설치본은 실행 중에 내려받는 것이 없게 만들었다(패키지를 미리 설치). 인터넷을 끊고 위 1~8을 하면 된다 |
| ⑦ | 관리자 권한이 없는 계정 | 확인 못 함 — 설치는 사용자별(권한 요청 없음)로 만들었다 |
| ⑧ | 보안 프로그램(DRM)이 있는 PC | 확인 못 함 — 사용자 폴더의 `python.exe` 실행과 터미널에서 프로그램 띄우기가 막히는지가 관건이다 |

개발 PC에서는 임시 폴더에 조용히 설치해(작업 없음) 1~8에 해당하는 것을 자동으로 돌리고 제거했다. 시작 메뉴 바로 가기·우클릭 메뉴·대화상자가 있는
보통 설치(위 표 그대로)는 사람이 한 번 해 봐야 한다.

## 알려진 것

- 아이콘이 아직 없어 바로 가기와 작업 표시줄에 Python 아이콘이 보인다(D1).
- WebView2 런타임이 없는 PC에서는 설치할 때 알리기만 한다 — 설치 도우미를 품는 것은 D5.
- 터미널에서 `equion` 명령이 도는 중에 Ctrl+C를 누르면 '일괄 작업을 끝내시겠습니까 (Y/N)?'가 뜰 수 있다(`equion.cmd` — 전용 실행기를 만들 때 푼다).
- 화면은 식 작업대 한 화면뿐이다. 탭·사이드바·작업 기록 띠·md 보기는 D1.
