# Equion Desk 설치 점검표 (D0 시험판 · D1 뼈대)

설치 파일 하나로 어떤 PC에서든 똑같이 도는지 보는 표다. 확인할 위험은 둘 — ① 식을 고치고 추정 결과를 보기까지 1초 안(성공 기준 S1),
② 설치만 하면 작동(S10). 넘지 못하면 런타임 방식을 다시 고른다(DECISIONS D39). 계획은 [`DESK_DEVPLAN.md`](DESK_DEVPLAN.md).
D1(뼈대)부터는 같은 표로 화면의 틀 — 프로젝트 탭·작업 기록 띠·바뀜 알림·지난 화면 — 도 함께 본다(2026-11-11, 화면이 바뀌어 순서를 고쳤다).

## 설치 파일

- **받기**: 저장소의 Actions → 가장 최근 CI 실행 → 작업 결과물 `EquionDesk-setup`(CI가 만들어 설치·기동 시험까지 한 파일, 14일 동안 남는다).
- **직접 만들기**(Windows, Inno Setup 6 필요 — 인터넷은 만들 때만): `uv run python desk/build/make.py` →
  `desk/dist/EquionDesk-0.1.0.dev0-setup.exe`(48MB). 설치 파일은 저장소에 넣지 않는다 — 다른 PC에는 이 파일만 옮긴다.

서명이 없어 처음 실행할 때 Windows SmartScreen이 "PC 보호" 창을 띄운다 — '추가 정보' → '실행'.

## PC마다 할 일 (5~10분)

| # | 할 일 | 기대 |
|---|---|---|
| 1 | 설치 파일 실행 — 관리자 권한을 묻지 않아야 한다 | 설치 20초 안팎, `%LOCALAPPDATA%\Programs\EquionDesk`(243MB) |
| 2 | 시작 메뉴의 **Equion Desk** 실행 | 창이 뜨고 첫 화면('폴더 열기…'·'예제 프로젝트 만들기'). 창과 작업 표시줄의 아이콘이 청록 네모(Python 아이콘이 아니다) |
| 3 | **예제 프로젝트 만들기** | 문서 폴더의 `Equion\example1`이 탭으로 열린다. 왼쪽에 모형 셋·블록 셋·부품 여섯, 아래 상태줄에 '작업 프로세스 준비됨' |
| 4 | 왼쪽에서 `CN`(demand 블록) 누르기 | 식 작업대 탭이 열리고 식 `CN c Y CN(-1)`이 놓인다 — **아직 계산하지 않는다**(아래 띠가 비어 있다) |
| 5 | **추정**(또는 Ctrl+Enter) | 계수표·진단·차트. 결과 머리의 '화면까지'가 **1초 안**(개발 PC 0.06초). 아래 띠에 `cn_0001 · Desk · 방금` |
| 6 | 식을 `CN c Y CN(-1) CN(-2)`로 고쳐 Ctrl+Enter | 항이 넷인 결과, 띠에 `cn_0002`. 차트에 마우스를 올리면 그 기간의 값 |
| 7 | 오른쪽 터미널에서 `python -c "import sys; print(sys.executable)"` | 설치 폴더의 `runtime\python.exe` — PC의 다른 Python이 아니다 |
| 8 | 터미널에서 `equion --version` · `equion hs main` | 판 번호 · 과거 재현 결과 글. **띠에 `hs_0001 · 터미널 · 방금`이 뜬다** — 누르면 표와 차트의 결과 카드 |
| 9 | '개요' 탭 → 모형 `main`의 **전망** | 띠 왼쪽에 도는 일(지난 시간·취소)이 보였다가 끝나면 `sim:…` 카드가 열린다 |
| 10 | 탐색기나 메모장으로 `example1\EQUATIONS\price.txt`에 주석 한 줄(`# 메모`)을 더해 저장 | 1~2초 안에 오른쪽 위에 "EQUATIONS/price.txt 파일이 바뀌었습니다" → '차이 보기'에 더한 줄 |
| 11 | (Claude Code가 있으면) 터미널에서 `claude` | Claude Code가 뜬다 — 없으면 건너뛴다. Claude가 `equion est …`를 돌리면 띠에 'Claude'로 뜬다 |
| 12 | 창을 닫고 시작 메뉴에서 다시 실행 | 프로젝트 탭·열어 둔 탭·쓰던 식이 그대로다(닫았다 열면 이어진다) |
| 13 | 창을 띄워 둔 채 시작 메뉴에서 한 번 더 실행(또는 탐색기에서 프로젝트 폴더 우클릭 → 'Equion Desk로 열기') | 새 창이 뜨지 않고 떠 있는 창이 앞으로 온다(폴더는 새 탭으로) |
| 14 | 창을 닫고 '앱 및 기능'에서 Equion Desk 제거 | 설치 폴더가 사라진다(문서 폴더의 예제와 설정 `%APPDATA%\EquionDesk`는 남는다) |

어긋난 곳은 번호와 화면에 보인 글(또는 화면 그림)을 적어 주면 된다. 창이 아예 뜨지 않으면 명령 프롬프트에서
`"%LOCALAPPDATA%\Programs\EquionDesk\runtime\python.exe" -I -m equion_desk --browser`를 돌려 나오는 글을 적는다.
설치 폴더만으로 도는지는 저장소에서 `python desk/build/smoke.py "%LOCALAPPDATA%\Programs\EquionDesk" --window`로 한 번에 볼 수 있다
(런타임 판·예제 프로젝트·추정 시간·과거 재현·전망·창은 하나).

## PC 여덟 가지

| # | PC | 상태 (2026-11-11) |
|---|---|---|
| ① | Python이 없는 PC | 일부 — CI의 실행기에서 설치·기동 시험(`desk-installer`)이 설치 폴더의 런타임만으로 돈다. 사람이 쓰는 PC는 확인 못 함 |
| ② | Python 3.9·3.15가 있는 PC | **통과**(개발 PC — 3.15가 있다): 터미널·작업 프로세스가 설치본의 3.13을 쓴다 |
| ③ | Anaconda가 있는 PC | 일부 — 개발 PC에 지워진 Anaconda의 레지스트리 항목이 남아 있고 영향이 없다. Anaconda가 살아 있는 PC는 확인 못 함 |
| ④ | `PYTHONPATH`·`PYTHONHOME`이 설정된 PC | **통과**(변수를 일부러 틀리게 주고 — 같은 이름의 가짜 `numpy`까지 두고 — 실행): 앱·작업 프로세스·터미널이 읽지 않는다. 자동 시험 D13·E3·E4, 기동 시험 6 |
| ⑤ | 깨진 바로 가기가 남은 PC(지워진 Python을 가리키는 chocolatey 바로 가기) | **통과**(개발 PC가 그렇다) |
| ⑥ | 인터넷이 없는 PC | 확인 못 함 — 설치본은 실행 중에 내려받는 것이 없게 만들었다(패키지를 미리 설치, 화면은 바깥 주소로 나가지 않는다). 인터넷을 끊고 위 1~10을 하면 된다 |
| ⑦ | 관리자 권한이 없는 계정 | 확인 못 함 — 설치는 사용자별(권한 요청 없음)로 만들었다 |
| ⑧ | 보안 프로그램(DRM)이 있는 PC | 확인 못 함 — 사용자 폴더의 `python.exe` 실행과 터미널에서 프로그램 띄우기가 막히는지가 관건이다 |

개발 PC에서는 임시 폴더에 조용히 설치해(작업 없음) 기동 시험(`smoke.py --window` — 위 1~9·13에 해당)을 돌리고 제거했다. 시작 메뉴 바로 가기·
우클릭 메뉴·대화상자가 있는 보통 설치(위 표 그대로)는 사람이 한 번 해 봐야 한다.

## 알려진 것

- WebView2 런타임이 없는 PC에서는 설치할 때 알리기만 한다 — 설치 도우미를 품는 것은 D5.
- 터미널에서 `equion` 명령이 도는 중에 Ctrl+C를 누르면 '일괄 작업을 끝내시겠습니까 (Y/N)?'가 뜰 수 있다(`equion.cmd` — 전용 실행기를 만들 때 푼다).
- 화면은 뼈대까지다(D1): 식 작업대의 후보 목록·겹쳐 보기·채택과 파일 고치기는 D2a, 조립·과거 재현 화면은 D3. 그 전에는 '터미널로' 단추가
  명령을 터미널에 붙여 준다(Enter는 직접).
- 파일 보기는 읽기 전용이다. 정의 파일은 편집기·Lectern·터미널(Claude)로 고치고, 고친 것은 바뀜 알림으로 뜬다.
- 큰 모형의 과거 재현은 몇 초가 걸린다 — 작업 줄에 지난 시간과 취소가 보인다(진행률은 D3).
