# 방정식 함수·지시자

식(추정식·항등식·genr·eval)에 쓰는 것 한 표. 문법 설명과 예는 [방정식 문법](../explain/equations.md).
아래 목록이 파서의 허용 목록과 같은지는 이 문서를 만들 때 확인합니다(맨 아래 블록).

## 수학 함수

| 표기 | 뜻 |
|---|---|
| `log(X)` · `exp(X)` · `abs(X)` · `sqrt(X)` | 자연로그 · 지수 · 절댓값 · 제곱근(`@log` 등도 같다) |
| `X^2` = `X**2` | 거듭제곱 |
| `+ − * /` · 괄호 · 숫자 | 사칙연산 |

## 시계열 연산

| 표기 | 뜻 | 펼친 식 |
|---|---|---|
| `X(-k)` · `X.t(-k)` | k기 전(시차) | |
| `X(k)` · `X.t(k)` | k기 뒤(선행 — [MCE](../explain/dynamics.md)) | |
| `X(-1 to -4)` · `X.t(-1 to -4)` | 시차 범위(추정식에서 항 여러 개로) | `X(-1) X(-2) X(-3) X(-4)` |
| `d(X)` · `d(X, n)` · `d(X, n, s)` | 차분 · n차 차분 · n차 + 계절(s기) 차분 | `X − X(-1)` … |
| `dlog(X[, n, s])` | 로그 차분 | `d(log(X), n, s)` |
| `X.diff` | 1차 차분 | `X − X(-1)` |
| `X.qoq` | 전기 대비 % (연간 불가) | `100·(X/X(-1) − 1)` |
| `X.yoy` | 전년동기 대비 % (분기 4 · 월 12 · 연 1기) | `100·(X/X(-k) − 1)` |
| `X.gr(n)` | n기 전 대비 % | `100·(X/X(-n) − 1)` |
| `X.ma(n)` | n기 이동평균 | `(X + … + X(-(n−1)))/n` |
| `@pc(X)` · `@pch(X)` | 전기 대비 % · 비율 | |
| `@pca(X)` | 연율화한 전기 대비 % | `100·((X/X(-1))^k − 1)` |
| `@pcy(X)` · `@pchy(X)` | 전년동기 대비 % · 비율 | |
| `@movav(X, n)` · `@movsum(X, n)` | n기 이동평균 · 이동합 | |

연산은 이어 쓸 수 있습니다(`X.t(-4).ma(2)`, `(CPI/KRW).ma(2)`, `log(Y).t(-1)`).

## 지시자 — 자동으로 만들어지는 열

| 표기 | 뜻 |
|---|---|
| `@trend` | 0, 1, 2, … (자료 처음부터) |
| `@seas` | 계절 더미 묶음(추정식에서 — 상수항이 있으면 하나 뺀다). 분기 `_Q1`~`_Q4`, 월 `_M1`~`_M12`, 연간 불가 |
| `@seas(n)` | n번째 계절 더미 하나(genr·eval에서도) |
| `@d(P)` · `@d(P1:P2)` | 그 시점(구간)만 1 |
| `@step(P)` | 그 시점부터 1 |

시점 `P`는 워크파일 주기로 씁니다(분기 `2008Q4` · 월 `2008M10` · 연 `2008`).

## 추정식 전용

| 표기 | 뜻 |
|---|---|
| `c` | 상수항 |
| `c(n)` | 비선형 식의 계수(`Y = c(1) + c(2)*X`) |
| `ar(1)` · `ar(1 to 4)` | AR(p) 오차 |
| `pdl(X, k, d[, 1\|2\|3])` | 다항 분포시차(시차 k, 차수 d, 끝점 제약) |

## 줄 끝 지시

| 표기 | 뜻 |
|---|---|
| `@smpl S E` | 이 식만의 표본 |
| `@inst Z1 Z2 …` (또는 `@ Z1 Z2`) | 도구변수(2SLS·GMM·LIML) |
| `@coef v1 v2 …` | 고정 계수(쓴 항 순서) |
| `@start v1 v2 …` | 비선형 식의 시작값 |
| `@def 이름 = 식` (방정식 파일의 줄) | 매크로 — 뒤 줄에서 이름을 식으로 바꾼다 |

## 쓸 수 없는 이름

변수·시리즈 이름으로 `C`(상수항)와 함수 이름 `LOG`·`EXP`·`ABS`·`SQRT`·`D`·`DLOG`는 쓸 수 없습니다(대소문자 무시).

## 한도

| 항목 | 한도 |
|---|---|
| 식 하나의 글자 수 | 20,000 |
| 식 트리 깊이(괄호 중첩·연산 사슬) | 250 |
| 시차·선행·차분·이동평균 길이 | 1,000 |
| 시차 범위 하나가 펼치는 항 | 100 |
| 추정식 하나의 항(펼친 뒤) | 500 |
