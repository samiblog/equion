# 사례 연구: Klein형 모형

교과서에 자주 나오는 Klein 모형 I의 구조로 연립방정식 모형의 기본기를 처음부터 끝까지 따라갑니다: 식별, 단일식 OLS의 치우침,
2SLS·3SLS·FIML, 추정한 식으로 모델 만들기, 과거 재현, 승수, 동태 안정성. 자료는 패키지에 든 가상 자료 `klein_like`입니다
([예제 자료](../reference/datasets.md#klein_like--klein-모형-i-구조의-가상-자료)). 참 계수를 알고 있으므로 방법마다 결과가 참값과 얼마나
가까운지 직접 볼 수 있습니다. 실제 Klein 자료로 하는 법은 마지막 절에 있습니다.

## 1. 모형

행동식 셋과 항등식 셋입니다(이름 `C`는 상수항이라 소비는 `CONS`, 이윤은 `PR`).

| 식 | 내용 |
|---|---|
| 소비 | `CONS = a₀ + a₁·PR + a₂·PR(-1) + a₃·(WP + WG)` |
| 투자 | `I = b₀ + b₁·PR + b₂·PR(-1) + b₃·K(-1)` |
| 민간 임금 | `WP = c₀ + c₁·X + c₂·X(-1) + c₃·A` |
| 총수요 | `X = CONS + I + G` |
| 이윤 | `PR = X − T − WP` |
| 자본 | `K = K(-1) + I` |

내생변수는 `CONS`·`I`·`WP`·`X`·`PR`·`K` 여섯, 외생변수는 `G`(정부지출)·`T`(세금)·`WG`(정부 임금)·`A`(추세)입니다.

```python
import pandas as pd

import equion as eqn

kw = eqn.datasets.load("klein_like")
print(kw)
print(kw.to_pandas(["CONS", "I", "WP", "X", "PR", "K"], labels=True).loc[["1921", "1950", "1990"]].round(1))
```

## 2. 식별

같은 기의 `PR`·`X`는 내생이라 오차와 상관됩니다. 도구변수는 외생변수와 미리 정해진 변수(시차 내생변수)입니다:
`G`·`T`·`WG`·`A`·`PR(-1)`·`K(-1)`·`X(-1)`에 상수항을 더하면 8개. 각 식의 계수는 4개이므로 식마다 도구가 계수보다 많아(차수 조건)
과대식별입니다.

## 3. 방법별 추정 비교

같은 식을 네 방법으로 추정해 참값과 나란히 놓습니다. FIML은 시스템 식의 목표변수만 내생으로 보므로, 항등식이 정하는 `PR`·`X`를
식 안에 대입해 다시 씁니다(`PR = CONS + I + G − T − WP`, `X = CONS + I + G`). 그러면 같은 기 내생변수가 모두 시스템의
목표변수가 되어 FIML이 그 관계를 우도에 넣습니다.

```python
eqs = ["CONS c PR PR(-1) WP+WG", "I c PR PR(-1) K(-1)", "WP c X X(-1) A"]
inst = "@inst G T WG A PR(-1) K(-1) X(-1)"

est = {}
for method in ["ols", "tsls", "three_sls"]:
    s = kw.system(f"s_{method}").append(*eqs, inst)
    getattr(s, method)()
    est[method] = s.coefs

fiml = kw.system("s_fiml").append(
    "CONS = c(1) + c(2)*(CONS + I + G - T - WP) + c(3)*PR(-1) + c(4)*(WP + WG)",
    "I = c(5) + c(6)*(CONS + I + G - T - WP) + c(7)*PR(-1) + c(8)*K(-1)",
    "WP = c(9) + c(10)*(CONS + I + G) + c(11)*X(-1) + c(12)*A")
fiml.fiml()
est["fiml"] = fiml.coefs

true = [16.4, 0.125, 0.163, 0.79, 28.2, -0.013, 0.756, -0.195, 1.8, 0.4, 0.181, 0.15]
table = pd.DataFrame(est)
table["참값"] = true
table.index = ["소비:c", "소비:PR", "소비:PR(-1)", "소비:W", "투자:c", "투자:PR", "투자:PR(-1)", "투자:K(-1)",
               "임금:c", "임금:X", "임금:X(-1)", "임금:A"]
print(table.round(3).to_string())
```

읽는 법:

- **OLS**는 같은 기 이윤의 계수(`소비:PR` · `투자:PR`)를 크게, 전기 이윤의 계수를 작게 잡습니다. 이윤이 소비·투자와 같은 기에 함께
  정해지기 때문입니다(동시성 편의).
- **2SLS·3SLS**는 도구변수로 그 편의를 줄여 참값 쪽으로 옵니다. 3SLS는 식 사이 오차 상관까지 써서 2SLS와 비슷하거나 조금 더 효율적입니다.
- **FIML**(항등식 대입)은 3SLS와 거의 같습니다 — 둘은 점근적으로 같은 추정량입니다. 항등식을 대입하지 않고 원래 식 그대로 FIML을
  돌리면 `PR`·`X`를 외생으로 다뤄 OLS와 비슷해지고, Equion이 경고합니다([튜토리얼 7](../tutorial/07-systems.md)).
- 표본이 70기라 모든 계수가 참값과 같지는 않습니다(투자·임금 식 상수항).

3SLS 결과표와 식 사이 제약 검정(같은 기 이윤과 전기 이윤의 효과가 같은가):

```python
s3 = kw.obj("s_three_sls")

w = s3.wald("c(2) = c(3)")
print("5%에서 기각:", w.reject(0.05))
```

## 4. 모델로 묶어 과거 재현

추정한 시스템을 모델에 넣고 항등식을 더해 1922~1990을 동적으로 풉니다.

```python
km = kw.model("m_3sls").merge(s3).append("X = CONS + I + G", "PR = X - T - WP", "K = K(-1) + I")
r = km.solve("1922", "1990")
print(r.statistics()[["RMSPE", "MAE", "mean_error"]].round(2).to_string())
```

## 5. 승수 — 방법에 따라 정책 효과가 달라진다

정부지출 `G`를 1960년부터 1만큼 계속 늘렸을 때 총수요 `X`의 반응을 OLS 모델, 3SLS 모델, 참 계수 모델에서 비교합니다.
참 계수 모델은 `@coef`로 계수를 고정한 식으로 만듭니다.

```python
ids = ("X = CONS + I + G", "PR = X - T - WP", "K = K(-1) + I")
m_ols = kw.model("m_ols").merge(kw.obj("s_ols")).append(*ids)
m_true = kw.model("m_true").merge(
    kw.equation("t_cons").ls("CONS c PR PR(-1) WP+WG @coef 16.4 0.125 0.163 0.79"),
    kw.equation("t_i").ls("I c PR PR(-1) K(-1) @coef 28.2 -0.013 0.756 -0.195"),
    kw.equation("t_wp").ls("WP c X X(-1) A @coef 1.8 0.4 0.181 0.15")).append(*ids)

mult = {}
for label, model in [("OLS", m_ols), ("3SLS", km), ("참 계수", m_true)]:
    x = model.multipliers("G", 1.0, "1960", "1969").level["X"]
    mult[label] = x.set_axis(x.index.year)
print(pd.DataFrame(mult).round(2).to_string())
```

바꿀 수 있다는 것이 연립방정식 추정을 따로 배우는 이유입니다. 승수가 몇 해 동안 커졌다가 줄어드는 것은 투자와 자본스톡이 만드는
경기 순환입니다.

## 6. 동태 안정성

그 순환이 사라지는지, 커지는지 동반행렬 고윳값으로 봅니다([해설](../explain/dynamics.md)).

```python
import numpy as np

sv = km.stability("1960")
sv.output(4).show()
lam = max(sv.eigenvalues, key=abs)
print(f"순환 주기 약 {2 * np.pi / abs(np.angle(lam)):.1f}년")
print(m_true.stability("1960"))
```

쓰기 전에 꼭 확인할 점입니다.

## 7. 실제 Klein 자료로

실제 자료(미국 1920~1941)는 이용 조건이 분명하지 않아 패키지에 넣지 않았습니다. 직접 구한 파일(첫 열이 연도)을 `eqn.datasets.klein`으로 열면
열 이름을 바꿔 줍니다([자세히](../reference/datasets.md#실제-klein-모형-i-자료-쓰기)). 실제 자료는 `K1`(전년 말 자본)을 줍니다.

<!-- skip -->
```python
wf = eqn.datasets.klein("klein.csv")
wf.smpl("1921", "1941")
s = wf.system("klein").append("CONS c PR PR(-1) WP+WG", "I c PR PR(-1) K1", "WP c X X(-1) A",
                              "@inst G T WG A PR(-1) K1 X(-1)")
for method in ("ols", "tsls", "three_sls"):
    getattr(s, method)()
    print(method, s.coefs.round(3).tolist())
```

결과는 계량경제학 교과서(예: Greene *Econometric Analysis*의 Klein 모형 I 예)의 표와 비교할 수 있습니다. 판과 반올림에 따라 끝자리가 다를 수 있습니다.
