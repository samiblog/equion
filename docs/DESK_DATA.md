[`DESK.md`](DESK.md) 4판의 K8(자료 관리)을 다섯 질문으로 다시 정리하고, 빈 곳을 채운 안이다. 채택되면 K0·K8·§9·§11에 옮긴다.

| 질문 | 한 줄 답 |
|---|---|
| 처음 자료는 어떻게 불러오나 | 원자료 파일을 넣고, 불러오기 화면에서 어느 칸을 어떤 시리즈로 읽을지 짝지어 저장하고, '자료 만들기'로 첫 자료 회차를 만든다 |

| 다른 곳의 작업을 가져올 수 있나 | 된다 — Desk 프로젝트·git·equion 워크파일·옛 형식·다른 프로그램의 CSV와 식 글, 다섯 길 |

| 업데이트하면 로직과 통계치는 | 로직(정의)도 통계치(기록)도 그대로 남는다. 새 자료로 다시 계산하는 일은 사람이 '다시'를 누를 때만 하고, 그 사이 옛 결과에는 '자료 회차 다름'이 붙는다 |

## 1. 처음 자료는 어떻게 불러오나

세 걸음이다 — **원자료 넣기 → 짝짓기(불러오기 화면) → 자료 만들기**. 원자료 파일은 받은 그대로 두고, "어느 칸을 어떤 시리즈로 어떻게 읽는지"를 정의로 남긴다.

| 들어오는 길 | 어떻게 | 지금 equion |
|---|---|---|
| 엑셀·CSV 파일 | W4 '원자료 넣기'(파일 고르기·끌어 놓기) → `DATA/raw/`에 복사 | 첫 열이 날짜인 표만 읽는다 — 불러오기 화면이 넓힌다(새로) |
| 클립보드의 표 | '붙여 넣어 원자료로' — 엑셀에서 복사한 표를 CSV로 `DATA/raw/`에 저장, 붙인 날·출처 메모 | 새로 |
| 통계 사이트(ECOS·KOSIS) | 터미널의 `equion data fetch` — 사람(이나 시킨 Claude)이 친 명령. 앱 자신은 인터넷에 닿지 않는다 | ROADMAP 0.8 |
| 워크파일·옛 형식 | '가져오기'(§3) | `wfopen`·`equion convert` 있음 |
| 예제 자료 | '새 프로젝트 — 예제로' | `eqn.datasets` 있음 |

**불러오기 화면**(W4):

```text
 원자료 [국민계정_2026-11.xlsx ▾]  시트 [실질 ▾]  열 이름 줄 [3]  단위 줄 [4]  시점 (•)행으로 ( )열로
 ─ 읽은 그대로 ───────────────────────────────────────────────
   시점      민간소비     총고정자본형성   수출
   2003/4    123,456     45,678          –          ← '–'는 결측으로 볼 칸(노랑)
   2004/1    124,010     46,102          88,231
 ─ 읽은 것 ─────────────────────────────────────────────────
   주기 분기(A열 '2003/4' 꼴) · 1995Q1~2025Q3 · 숫자 꼴 '1,234' · 결측 표시 '–' '…'
 ─ 짝짓기 ─────────────────────────────────────────────────
   민간소비        → [CN] 단위 [십억원(연쇄)] 설명 [민간소비, 실질]  변환 [계절조정 STL 승법 ▾]
   총고정자본형성   → [I ] …
 ─ 미리보기: 고른 열의 원계열·변환 결과 차트 ─────────────          [시리즈 정의 저장]
```

- **표 모양을 고른다**: 시트, 열 이름 줄·단위 줄, 시점이 행으로 내려가는지 열로 가는지(통계표는 기간이 열로 가는 경우가 많다), 시점 꼴
  (`2003/4`·`2003.Q4`·`2003-10`·`2003년 4/4분기` → 주기 추론, 모르면 묻는다), 숫자 꼴(천 단위 쉼표·괄호 음수), 결측 표시(`–`·`…`·`x`·빈칸).
- **이름은 사람이 짓는다**: 시리즈 이름은 영문·숫자·`_`(K0), 한글 열 이름은 설명이 된다. Claude가 있으면 이름을 제안받을 수 있다.
- **저장하면 두 가지가 생긴다**: 출처 항목(파일·시트·표 모양 = **불러오기 틀**)과 시리즈 항목(어느 열·변환·단위·설명). 틀은 자료를 갱신할 때 그대로 다시 쓰인다(§4).
- 그다음 '자료 만들기' → 첫 회차 → '이 회차로 바꾸기'.

```toml
# DATA/series.toml (초안)
[source.na]
file = "DATA/raw/국민계정_2026-11.xlsx"
sheet = "실질"
header_row = 3            # 열 이름 줄
unit_row = 4
time_axis = "rows"        # 시점이 행으로 내려간다("columns"면 열로)
missing = ["–", "…"]
thousands = ","

[series.CN]
from = "na:민간소비"       # 열 위치가 아니라 열 이름으로 찾는다
seas = "stl"
unit = "십억원(연쇄)"
desc = "민간소비, 실질, 계절조정"
```

## 2. 작업 중간에 저장했다가 이어 하려면

따로 '저장 파일'(워크파일)이 없다. **프로젝트 폴더가 곧 작업**이라, Desk를 닫았다 다시 열면 그대로 이어진다.

| 무엇 | 언제 남나 | 어디 |
|---|---|---|
| 정의 — 시리즈·식·블록·모형·가정·보정항·시나리오·보기 | '저장'·'채택'·'적용'을 누를 때(바뀜 기록 K7) | `DATA/`·`EQUATIONS/`·`ASSUMPTIONS/`·`SCENARIOS/`·`equion.toml` … |
| 결과 — 추정·HS·전망·분석 | 계산하는 순간 저절로 | `work/est`·`hs`·`sim`·`an` |
| 노트·보고서 | md 저장(Ctrl+S) | `notes/`·`reports/` |
| 지금 자료 회차 | '이 회차로 바꾸기' | `equion.toml`의 `[data] vintage`(Q19) |
| 저장하지 않은 고침 — 식 칸에 쳐 둔 글, 넣다 만 표 값, 저장 전 짝짓기 | 치는 동안 | 초안 `work/desk/drafts/`(Q21) |
| 화면 상태 — 열린 탭·배치·고른 후보 | 닫을 때 | `work/desk/state.json` |

- **닫을 때**: 저장하지 않은 고침이 있으면 목록을 보이고 '저장'·'초안으로 두기'·'버림'을 고른다. 초안은 정의가 아니다 — 계산·조립에 쓰이지 않고, 다시 열면 초안 배지와 함께 돌아온다.
- **다시 열 때**: 같은 탭, 상태줄의 자료 회차, "Desk가 꺼져 있는 동안 바뀐 파일"(K7), 작업 기록 띠의 마지막 기록.
- **이정표**(새로): 중요한 때(예: "2026-11 전망 확정")에 '이정표 만들기' — 그때의 정의 내용·자료 회차·고정한 기록을 이름으로 묶어 둔다(`work/milestones/`).
  나중에 '이정표와 비교'·'정의를 이정표로 되돌리기'. 프로젝트가 git이면 사람이 고를 때 git 태그로도 남긴다.

## 3. 다른 곳에서 한 작업을 가져와 이어 할 수 있나

된다. 가져오는 것에 따라 다섯 길이다.

| 가져오는 것 | 어떻게 | 무엇이 되나 |
|---|---|---|
| 다른 PC의 Desk 프로젝트 | 폴더째 복사해 열기. 또는 '프로젝트 묶어 보내기'(zip, 새로)로 받은 묶음을 '묶음 열기' | 그대로 이어 한다 — 정의·노트·보고서·고정한 기록·자료 회차. 원자료를 넣을지는 묶을 때 묻는다(Q20) |
| git 저장소 | clone 후 열기 | 정의만 온다(Q9 — `work/`·`DATA/raw/`는 기본 제외). 원자료를 따로 받아 넣고 '자료 만들기'로 회차를 다시 만든다 |
| equion 라이브러리 작업 — 워크파일 `.eqw`·방정식 파일·CSV·스크립트 | '가져오기'(새로) | 워크파일의 시리즈 → 원자료(CSV)와 1:1 시리즈 정의, 방정식 객체 → 블록 파일과 후보 기록, 모형 객체 → `[model]`, 스크립트 → `scripts/`(`equion run`으로) |
| 옛 형식 — `.wt`·`.mmw`·레거시 pickle | `equion convert`로 `.eqw`를 만든 뒤 위처럼. pickle은 믿는 파일만(`--allow-pickle`, D18) | 위와 같다 |
| 다른 프로그램(EViews 등)의 작업 | 자료는 CSV·XLSX로 내보내 '원자료 넣기', 식은 글로 붙여 넣기 — 방정식 문법이 `X(-1)`·`@pc` 같은 표기를 읽는다 | `.wf1`·`.prg`는 열지 않는다(D13 — 비공개 형식을 역설계하지 않고 프로그램 실행기를 만들지 않는다) |

- '가져오기'의 결과 화면에는 들어온 것, 들어오지 못한 것과 까닭, 알아서 한 것(바꾼 이름 등)이 보인다. 바뀜 기록에는 "가져오기(원본 경로)"로 남는다.
- 거꾸로 Desk 프로젝트를 Python에서 쓰려면 `eqn.project()`(K8-6) — 지금 자료 회차와 기록을 읽는다.

## 4. 자료 업데이트는 어떻게 하나

다섯 걸음 모두 사람이 누르는 단추다. 저절로 바뀌는 것은 없다.

1. **원자료 바꾸기**: 새 파일을 고르고, 그 파일이 바꿀 출처(`na`)를 고른다. 옛 파일은 지우지 않는다 — 같은 이름이면 날짜를 붙여 나란히 둔다.
   출처 항목의 `file`이 새 파일로 바뀌고 바뀜 기록에 남는다.
2. **틀 검사**: 저장된 불러오기 틀로 새 파일을 읽어 본다. 시트·열 이름을 다 찾았는지, 새로 생긴 열·없어진 열, 주기·시작 시점이 같은지.
   어긋나면 불러오기 화면이 그 자리를 보이고 사람이 고친다.
3. **자료 만들기** → 새 회차(예: `d2026-12a`). 결과 화면에 새 기간, 개정된 값(시리즈·기간·크기 — 표와 차트), 알아서 한 것.
4. **이 회차로 바꾸기** — 이때부터 새 계산이 새 회차를 쓴다. 옛 회차는 남는다(재현 — S7).
5. **회차 바꾼 뒤 할 일** 화면이 뜬다(§5).

통계 사이트에서 받는 자료(`equion data fetch`)는 1을 명령이 하고, 2부터 같다. 출처 하나만 바뀌어도 회차는 전체를 새로 만들고, 다른 값 목록에는 바뀐 시리즈만 나온다.

## 5. 업데이트하면 기존 분석 로직과 통계치는 어떻게 되나

**로직도 통계치도 그대로 남는다. 새 자료로 다시 계산하는 일은 사람이 '다시'를 누를 때만 한다.**

| 무엇 | 회차를 바꾸면 | 다시 하려면 |
|---|---|---|
| 로직 — 시리즈 정의·식·블록·모형·시나리오·노트의 명령·보고서에 보낸 모양 | 그대로 — 자료와 따로 있다 | 같은 로직을 새 자료에 다시 적용하면 된다 |
| 결과 — 추정·HS·전망·분석 기록(통계치) | 그대로 남고 '자료 회차 다름' 배지 | '다시 추정'·'다시 풀기'·'노트 전체 실행' → 새 기록(옛 기록과 나란히) |
| 모형이 쓰는 계수 | 채택한 추정 기록의 계수 그대로(옛 회차로 추정한 것) | '다시 추정' → 비교 → '새 계수 채택'(Q18) |
| 노트·보고서의 결과 구역 | '낡음' · '더 새 기록 있음' | '노트 전체 실행' · '새 기록으로 바꾸기' |

**계수의 규칙**(새로 분명히 함): 모형은 식마다 **채택한 추정 기록의 계수**로 푼다. 블록 파일의 줄은 식의 글자이고, 어느 기록의 계수를 쓰는지는
`EQUATIONS/adopted.toml`(`"demand:CN" = "est:cons_c5"`)에 적힌다. 새 회차로 HS·전망을 풀면 알아서 한 것에 "식 10개의 계수가 옛 회차(d2026-11c)로 추정됨"이 적힌다.
풀 때마다 다시 추정하지 않는다 — 그러면 같은 모형이 자료 회차마다 몰래 달라진다.

**회차 바꾼 뒤 할 일**(새로) — 회차를 바꾸면 뜨는 화면. 영향받는 것을 모두 모아 보이고, 단추를 누를 때만 다시 계산한다(`equion data impact`도 같은 목록).

```text
 자료 회차 d2026-11c → d2026-12a · 새 기간 2025Q4 · 개정 4분기(CN·I·Y)
 ───────────────────────────────────────────────────────────
 식 계수   10개가 옛 회차로 추정됨                          [모두 다시 추정 → 비교]
 HS       hs:hs_0031 (고정)                               [같은 조립으로 다시]
 전망      sim:2026-11_base · oil20 외 3                    [새 회차로 다시 풀기]
 노트      자료점검.md 구역 5 · hpi_invest.md 구역 3          [노트 전체 실행]
 보고서     2026-11_전망.md 구역 6                           [새 보고서 — 지난달에서]
```

**다시 추정한 통계치 비교** — '모두 다시 추정'을 누르면 식마다 새 추정 기록이 생기고, 옛 계수와 나란히 보인다(예시 수치).

```text
 식          계수(가장 크게 바뀐 것)    R²adj           SE         진단 바뀜     유의성
 demand:CN   Y 0.42 → 0.44 (+5%)      .9987 → .9986   .41 → .42  —            —
 demand:I    RR −0.08 → −0.03         .981 → .975     1.2 → 1.4  LM ✓ → !     RR t −2.4 → −0.9 (잃음)
 price:PY    E(-1) 0.11 → 0.12        .962 → .963     .30 → .30  —            —
 [바뀐 것만 보기]  [고른 식 새 계수 채택]  [모두 채택]  [옛 계수 유지]
```

- 채택은 사람이 고른다. 채택하면 `adopted.toml`이 바뀌고(바뀜 기록) 그 계수를 쓰는 HS·전망에 '낡음'이 붙는다.
- 표본: 식의 표본 끝을 '끝까지'(`last`)로 둔 식은 새 기간까지 늘어나 추정되고, 끝을 고정한 식은 같은 표본에서 개정만 반영된다 — 식마다 정의에 적힌 대로.
- 새 회차·새 계수로 HS를 다시 풀면 전후 비교에서 차이를 **자료 개정의 몫과 계수 변경의 몫**으로 나눠 보인다(옛 계수 + 새 자료 풀이를 하나 더 돌려 — 그것도 기록으로 보인다).
- 단위근 같은 분석은 '노트 전체 실행' 뒤 '이전 기록과 비교'로 판단이 바뀐 줄이 강조된다.
