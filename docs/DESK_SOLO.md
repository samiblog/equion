# Equion Desk — 혼자 하는 작업 장면 10가지 (2026-11-09)

Claude Code 없이 사람이 Desk만으로 일하는 장면 열 개다. Claude가 없는 PC든, Claude에게 맡기지 않기로 한 일이든, 손으로 하는 편이 빠른 일이든
Desk의 모든 기능은 손으로 된다([`DESK.md`](DESK.md) §2.1 두 길). 장면 8은 새로 더하는 '보고서로 보내기'([`DESK_ANALYSIS.md`](DESK_ANALYSIS.md) §5)를 쓴다.
Claude와 함께하는 장면은 [`DESK_SCENES.md`](DESK_SCENES.md)에 있다. 숫자는 모두 예시다.

## 무대

- **같은 화면**: 사이드바·작업대·작업 줄·작업 기록 띠·상태줄은 그대로다. 터미널도 그대로 있고 `equion`·`python`은 설치본의 것이다 — `claude`만 없다.
- **달라지는 것**: '맡기기'·'제안 받기' 단추는 흐리게 보이고, 누르면 Claude Code 설치 안내가 뜬다. 바뀜 기록의 '누가'에는 사람과 바깥(다른 편집기)만 남는다.
- **손버릇**: Ctrl+Enter 추정·풀기 · Ctrl+K 명령 찾기(모든 단추와 분석을 이름으로) · 우클릭 → 분석 · F1 도움말 · 표는 엑셀처럼 복사·붙여넣기.
- **모형**: Claude 장면과 같은 가상 분기 모형(`demand`·`external`·`price`·`finance`, 조립 `main`).

## 장면 1. 자료를 손으로 불러오기 — 미리보기·짝짓기·파생

**상황**: 인터넷이 막힌 업무 PC. 국민계정 엑셀과 월별 물가·금리 CSV를 메일로 받았다.

1. W4 '원자료 넣기'로 두 파일을 고른다. `DATA/raw/`에 복사되고 원자료 목록에 뜬다.
2. '불러오기'에서 엑셀의 '실질' 시트를 고르면 읽은 그대로의 표가 보인다. 위에는 Desk가 읽은 것 — "A열 `2003/4` 꼴을 분기로 읽음" — 이 있고,
   숫자가 아닌 칸('–', '…')은 노랗게 '결측으로 볼 칸'이다.
3. 열 머리를 눌러 짝짓는다: `민간소비` → `CN`, `총고정자본형성` → `I` … 열마다 단위·설명을 친다. 변환 칸에서 '계절조정: STL 승법'을 고르면
   미리보기 차트에 원계열과 조정 계열이 겹쳐 보인다(저장 전이라 아무것도 남지 않는다).
4. CSV에서는 `CPI` → `P`, `콜금리` → `R`, 둘 다 '분기 평균'.
5. '파생 시리즈 더하기' → 이름 `RR`, 식 `R - P.yoy`. 치는 동안 문법 검사가 돌고 미리보기 차트가 그려진다.
6. '저장' → `series.toml`·`derived.txt`에 항목이 생기고 바뀜 기록에 '사람'으로 남는다. '자료 만들기' → `d2026-11a` → '이 회차로 바꾸기'.
7. 결과 화면의 결측 1칸을 누르면 원자료의 그 칸(`실질!C42`)으로 간다. 받은 자료가 비어 있는 것이라 그대로 둔다 — 원자료는 고치지 않는다.

**남는 것**: 원자료 2 · 정의 파일 2 · 회차 `data:d2026-11a`.

## 장면 2. 식 하나 다듬기 — 1초 피드백으로 수십 번

**상황**: 수입함수 `external:M`을 다듬는다. 한 시간 동안 식을 수십 번 고친다 — Desk에서 가장 많이 하는 일이다.

1. 사이드바 부품에서 `external:M`을 더블클릭하면 W1에 지금 채택된 식이 뜬다.
2. 식 칸을 `log(M) c log(Y) log(E) log(M(-1))`로 고치고 Ctrl+Enter. 1초 안에 결과가 바뀐다. 기대 부호 칸(`[criteria]`)에서 `E`가 ✗다.
3. 고칠 때마다 Ctrl+Enter — 후보 목록에 `m1`·`m2`·`m3`…이 저절로 쌓인다(이름은 고칠 수 있다).
4. 차트 아래 표본 띠를 끌어 시작을 2000Q1로 옮기면 다시 추정된다. 표본이 다른 후보는 AIC·BIC 칸에 경고가 붙는다.
5. White '!' → '강건 SE로 다시 보기(HAC)'를 누르면 t값이 바뀐 계수표가 옆에 뜬다.
6. 잔차 차트에서 2009Q1이 크게 튄다. 그 점을 누르면 그 기간의 실측·적합·잔차와 입력값이 보인다. '이 기간 더미 넣기' → 식 칸에 `@d(2009Q1)`이 붙는다
   (계산은 Ctrl+Enter를 누를 때).
7. 재귀 계수·CUSUM 탭으로 안정성을, 단독 모의 탭으로 동태 적합을 본다.
8. 후보 목록에서 `m4`·`m7`을 겹쳐 보고 `m7`을 '채택'. 블록 파일이 바뀌고 바뀜 기록에 남는다. 이튿날 HS가 나빠 보이면 바뀜 기록에서 '되돌리기' 한 번이면 된다.

**남는 것**: 후보 기록 수십 개 · 블록 파일 1줄 변경.

## 장면 3. 후보 여러 개를 한 번에 — 후보 묶음

**상황**: 투자함수 후보를 넓게 보고 싶다. 스무 개를 하나씩 치기는 번거롭다.

1. W1 '후보 묶음 만들기'(새로) 폼: 종속 `dlog(I)`, 늘 넣을 것 `c`, 고를 칸 셋 —
   ① `dlog(Y)` | `dlog(Y(-1))` ② `RR(-1)` | `RR(-2)` | `RR(-1 to -2)` ③ (없음) | `log(I(-1)/Y(-1))`.
   아래에 만들어질 식 12개가 글자 그대로 보인다. 사람이 둘을 지운다.
2. '모두 추정' → 작업 줄 "10개 중 4" → 후보 목록에 `i1`~`i10`. 판단 기준(기대 부호·진단 유의수준)이 칸마다 색으로 보인다.
3. 표본 밖 RMSE 순으로 정렬하고 '부호 맞음 + LM 통과'로 거르면 셋이 남는다. 걸러진 일곱은 흐리게 남는다(지우지 않는다).
4. 셋을 겹쳐 보고 단독 모의를 견준 뒤 `i6`으로 '이 후보로 HS'. 채택은 HS를 본 뒤로 미룬다.
5. '노트로 저장' → `notes/invest_candidates.md`에 `equion est` 열 줄이 든 블록 하나가 생긴다. 다음 회차에는 '노트 전체 실행'으로 같은 묶음을 다시 돌린다.

**남는 것**: 후보 기록 10 · HS 기록 1 · 노트 1.

## 장면 4. 자료 점검 노트를 매달 다시

**상황**: 자료가 갱신될 때마다 주요 시리즈를 점검한다 — 계절조정 상태, 단위근, 이상치. 노트를 한 번 만들어 두고 매달 다시 돌린다.

1. 첫 달: W4에서 `CN` 우클릭 → 분석 → 계절조정 → 카드에서 '노트에 담기' → 새 노트 `notes/자료점검.md`. 묶음 `core` 우클릭 → 단위근 → '노트에 담기'(같은 노트 끝).
   기초 통계도 담는다.
2. 노트 탭에서 블록 사이에 글을 쓴다. "CN 계절 성분이 2020년에 흔들림 — 조정 계열을 따로 확인."
3. 다음 달 '이 회차로 바꾸기'를 누르면 노트의 결과 구역마다 '낡음'(자료 회차 다름)이 붙는다. '노트 전체 실행' → 블록마다 새 기록이 생기고 구역이 바뀐다.
   손으로 고친 구역이 없으니 묻지 않는다.
4. 구역 머리의 '이전 기록과 비교'를 누르면 지난달 카드와 나란히 보인다. 판단이 바뀐 줄(예: `log(I)` 단위근 → 엇갈림)이 강조된다.
5. 지난달 판단이 이제 맞지 않는 문장을 사람이 고친다.

**남는 것**: 노트 1(매달 같은 파일) · 분석 기록(매달 새로).

## 장면 5. 모형 조립과 원인 따라가기 — 손으로

**상황**: 블록 넷을 처음 조립해 모형 main을 만들고 HS로 검증한다.

1. W0 '새 모형' → 이름 `main` → 왼쪽 부품 목록에서 블록 넷을 끌어 넣는다. 저장하면 `equion.toml`에 `[model.main]`이 생기고 바뀜 기록에 남는다.
2. '조립 검사' → 내생 10 · 외생 5 · 동시 블록 1 · 문제 1: 모르는 변수 `SD`. W4에서 `SD`를 파생 시리즈로 정의하고 자료를 만든 뒤 다시 검사 → 문제 0.
3. W2 '풀기'(2005Q1~2019Q4, dynamic). 상태 띠의 2009Q1이 노랗다 — '일부식 제외'. 알아서 한 것: "POIL 2009Q1 결측 → price:P 식을 그 기간 뺌".
   사람이 정의에 `fill = "linear"`를 더해 그 칸을 '변환' 값으로 채우기로 정하고, 자료를 다시 만들어 HS를 다시 푼다.
4. 적합도 표에서 `I`가 나쁘다. 그 행을 누르면 원인 따라가기 패널에 I 식의 입력(Y·RR·I(-1))의 HS 오차가 뜬다. RR이 크다 → RR은 R과 P.yoy에서 온다 →
   finance 블록만 HS로 풀면 괜찮다 → price 블록만 풀면 P가 어긋난다.
5. 결론: 물가 동태가 문제다. W1에서 `price:P`를 다듬는다(장면 2처럼).

**남는 것**: 모형 정의 · 정의 변경 2 · HS 기록 여럿.

## 장면 6. 월간 전망 루틴 — 엑셀과 오가며

**상황**: 매달 하는 전망. 외생 가정은 부서의 엑셀 양식으로 받는다.

1. 새 원자료를 넣고 '자료 만들기' → '앞 회차와 다른 값'을 훑고 → '이 회차로 바꾸기'.
2. W3 가정 표: 받은 엑셀에서 유가·환율 경로를 복사해 표에 붙여 넣는다(Ctrl+V). 붙인 칸은 '가정'이다. 전망 구간을 다 덮지 못한 `WY`에 경고가 뜨자
   채우기 규칙을 `growth`(최근 여덟 분기 평균 증가율)로 고른다 — 그 칸은 '채움' 색.
3. 보정항: 규칙은 그대로 두고 `CN` 2026Q1에 판단 값 −0.2.
4. '풀기' → `sim:2026-12_base`. 지난달에 저장한 보기 `VIEWS/core_hs.toml`로 바로 같은 표와 차트가 뜬다. 연간 집계로 바꿔 본다.
5. '회차 비교'로 지난달 기준선과 견주고 '요인 나누기'(자료·가정·식) — 중간 풀이도 기록으로 보인다.
6. '엑셀로 내보내기' → `exports/`. 값 시트에 값의 종류·출처 시트가 함께 들어 있어 부서 동료가 어느 칸이 가정이고 어느 칸이 해인지 안다.

**남는 것**: 회차 1 · 가정 CSV 변경 · 전망 기록 · 내보내기 1.

## 장면 7. 위험 시나리오 셋 — 폼으로 만들고 한 표로

**상황**: 위험 시나리오 셋 — 유가 +20%, 세계수요 −2%, 환율 +10% — 을 만들어 한 표로 본다.

1. W3 '새 시나리오'(폼, 새로): 기준 가정 세트 `base`, 충격 표 — 변수 `POIL` · 시작 2026Q1 · 크기 +20% · 지속(끝까지). 저장하면 `SCENARIOS/oil20.toml`이 된다
   ('파일 보기'로 글도 보인다).
2. 같은 폼으로 `wy_m2`·`krw10`을 만든다. 유가와 환율이 함께 오르는 `oil_krw`는 충격 표에 두 줄을 넣는다.
3. 시나리오 목록에서 넷을 골라 '함께 풀기'(모형 main) → 작업 줄에 넷 → 기준선 대비 차이 표(시나리오가 열, 변수 × 연도가 행)와 차트.
4. Y 차이의 기여도 분해와 승수 표를 본다.
5. '이 보기 저장' → `VIEWS/risk.toml`. 다음 달에는 시나리오 파일을 그대로 두고 새 기준선 위에서 다시 푼다.

**남는 것**: 시나리오 파일 4 · 전망 기록 4 · 보기 1.

## 장면 8. 보고서로 보내기 — 분석 결과로 전망 보고서 md 만들기

**상황**: 이번 달 전망 보고서를 혼자 쓴다. 표 셋, 차트 둘, 위험 시나리오 표 하나, 부록에 단위근 표가 들어간다.

1. '새 보고서' → 빈 틀 → `reports/2026-12_전망.md`. 머리에 제목·날짜·자료 회차·모형이 채워지고, 절 제목은 사람이 고친다.
2. W3 기준선 결과에서 '보고서로 보내기'를 누르면 대화상자가 뜬다.

   ```text
   보낼 것   표 — 주요 지표          행  Y · CN · I · P · R
   모양      전년동기비 · 연간 집계 · 소수점 1        제목  표 1. 주요 지표 전망
   출처 줄   ☑ 자료: Equion sim:2026-12_base(자료 회차 d2026-12a)
   보낼 곳   reports/2026-12_전망.md › ## 전망 아래             [미리보기] [보내기]
   ```

3. 같은 결과의 Y 차트를 '전망 구간 음영'을 켜고 보낸다. 차트 자료는 `reports/2026-12_전망_data/`로 복사된다 — 보고서는 혼자 선다.
4. 장면 7의 보기 `risk`에서 시나리오 표를, 장면 4 노트의 단위근 구역에서 부록 표를 보낸다(노트의 구역에서도 바로 보낼 수 있다).
5. 글은 Desk의 md 편집이나 Lectern에서 쓴다. 보고서에는 명령 블록이 없다 — 읽는 글이다. 보낸 표·차트에는 보이지 않는 표시가 있어 Desk에서는 머리 띠
   (기록 이름·보낸 날)가 보인다. 표 1의 행 이름 'Y'를 '실질 GDP'로 손으로 고친다.
6. 발표 이틀 전에 자료가 개정되어 기준선을 다시 푼다(`sim:2026-12_base2`). '보고서 검사' → "구역 4개에 더 새 기록이 있음". '모두 새 기록으로 바꾸기' →
   구역마다 전후 차이(바뀐 숫자 강조)가 보이고, 손으로 고친 행 이름은 '남기기'로 고른다 → 적용.
7. Lectern에서 열어 슬라이드로 바꾸고 pptx로 낸다.
8. 다음 달: '새 보고서 — 지난달에서' → 구역마다 바꿔 낄 기록을 Desk가 제안한다(`sim:2026-12_base2` → `sim:2027-01_base`). 확인하고 적용하면 숫자는 끝 — 글만 고친다.

**남는 것**: 보고서 md 1 · 보고서 자료 폴더(CSV 5) · 보낸 기록은 정리 목록에 '보고서가 씀'으로 빠진다.

## 장면 9. 동료의 모형 검토 — 사람이 남기는 제안

**상황**: 동료가 만든 프로젝트 폴더를 받아 검토한다. 고칠 곳이 보여도 직접 고치지 않고 의견을 남기고 싶다.

1. Desk로 폴더를 연다. 상태줄에 자료 회차 `d2026-11c`(폴더 안 `work/`에 있다)와 모형 main. 작업 기록에서 동료가 고정한 기록 목록을 본다.
2. 고정한 HS 기록 → 조립 명세 → '그때 그대로 다시' → 차이 0. 내 PC에서도 같은 결과가 나온다.
3. 바뀜 기록으로 동료가 최근 무엇을 바꿨는지 시간순으로 훑는다(누가 · 무엇 · 차이).
4. `finance:R` 식의 표본이 짧아 보인다. W1에서 표본을 늘린 후보를 추정하고 '이 후보로 HS'로 확인한 뒤, 카드에서 '제안으로 남기기' → 까닭을 적는다
   ("2000년 이전 포함 시 HS의 R RMSPE 0.41 → 0.33"). `work/proposals/p7/`.
5. 폴더를 돌려보낸다. 동료가 Desk를 열면 제안 카드(누가: 검토자)가 뜨고, 적용·버림은 동료가 한다.

**남는 것**: replay 기록 · 후보·HS 기록 · 제안 1.

## 장면 10. 선언형으로 안 되는 일 — 스크립트로

**상황**: 기준년이 다른 두 계열을 이어 붙이는 특수 가공이 필요하다. 정의 파일의 변환으로는 안 된다.

1. 아무 편집기로 `scripts/link_series.py`를 쓴다. `eqn.project()`로 지금 자료 회차를 읽고 이은 계열을 CSV로 쓴다.
2. 파일 탭에서 스크립트를 우클릭 → 'Run' → 터미널에 `equion run scripts/link_series.py`가 Enter 없이 붙는다 — 사람이 Enter. 앱 안에서는 Python을 돌리지 않는다.
3. 실행 보고서(`out/<id>/`)가 작업 기록 띠에 뜨고, Desk의 실행 보고서 화면에 로그·만든 파일·종료 코드가 보인다.
4. 만든 CSV를 '원자료 넣기'로 넣는다. 출처 칸에는 실행 기록(`run:<id>`)과 스크립트가 적힌다. 정의에서 그 파일을 출처로 쓰고 '자료 만들기'.
5. 다음 달에도 쓰도록 자료 점검 노트(장면 4)에 Python 블록으로 넣어 둔다. 노트의 ▶는 터미널에 명령을 붙여 넣을 뿐이다.

**남는 것**: 스크립트 1 · 실행 보고서 1 · 만든 원자료 1(출처: 실행 기록).
