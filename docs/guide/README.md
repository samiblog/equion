# 가이드 — 사람과 상황별

튜토리얼은 기능을 차례로 배우고, 레시피는 할 일 하나를 처방합니다. 이 가이드는 **일하는 사람의 하루**를 따라갑니다 — 처음 써 보는 사람, 자기 모형을
옮겨 오는 사람, 매달 전망을 내는 사람, 식을 손보는 사람, 보고서를 쓰는 사람, Claude에게 맡기는 사람, 자동으로 돌리는 사람. 모두 이번 판의
**프로젝트**(블록·모형·자료 회차·작업 기록·스크립트)를 터미널 명령으로 씁니다.

| 가이드 | 이런 분에게 | 다루는 것 |
|---|---|---|
| [1. 처음 한 시간](01-first-hour.md) | 처음 써 보는 사람 | 예제 프로젝트로 한 바퀴 — 조립·추정·과거 재현·전망·보고서·스크립트·재연 |
| [2. 내 모형을 프로젝트로](02-my-model.md) | 자기 자료와 식이 있는 사람 | 엑셀 원자료의 불러오기 틀, 블록 파일, 모형 조립, 첫 회차, 내 월간 스크립트 |
| [3. 매달 하는 일](03-monthly.md) | 매달 전망을 내는 사람 | 받은 원자료 넣기, 미리보기, 실행, 자료 점검(개정·항등식), 지난달과 견주기, 재연 |
| [4. 식 고르기](04-equations.md) | 식을 손보는 사람 | 후보 추정·판단 기준·견주기·바꿔 끼운 과거 재현·채택·되돌리기·다시 추정 정책 |
| [5. 전망과 시나리오](05-forecast.md) | 전망을 짜는 사람 | 가정 경로·보정항·시나리오 파일, 기준선 대비, 지난 전망과 견주기 |
| [6. 분석·노트·보고서](06-reports.md) | 보고서를 쓰는 사람 | 분석 기록, 노트의 결과 구역, 보고서로 보내기, 새 기록으로 바꾸기, 엑셀 |
| [7. Claude와 함께](07-with-claude.md) | Claude에게 맡기는 사람 | 안내·스킬, 부탁하는 말, Claude가 한 일 확인, 제안 받고 적용·되돌리기 |
| [8. 막혔을 때](08-troubleshooting.md) | 누구나 | 흔한 오류와 고치는 법, 손으로 고친 구역, 되돌리기, 그때 그대로 다시 |
| [9. 자동으로 돌리기](09-automation.md) | 운영·자동화를 맡은 사람 | 종료 코드, `--json`(결과·오류), 예약 실행, CI |

## 시작하기 전에

설치는 [설치](../start/install.md)를 따릅니다. 이 가이드의 명령은 모두 터미널에서 칩니다(Windows는 PowerShell·명령 프롬프트·Lectern 터미널).
판을 확인합니다.

```console
$ equion --version
```
<!-- out -->
```text
$ equion --version
equion 0.9.0
```

## 이 가이드의 출력

`$`로 시작하는 줄이 칠 명령이고, 그 아래의 출력은 문서를 만들 때 **실제로 돌린 결과**입니다(`python docs/build_docs.py`가 채우고, CI가
`--check`로 다시 돌려 문서와 같은지 봅니다). 그래서 따라 치면 같은 출력이 나옵니다 — 다른 것은 날짜·시각, 자료 회차 이름(`d2026-11a`처럼
만든 달), 전망 기록 이름의 달(`sim:2026-11_base`)뿐입니다. 파일을 끌어다 놓는 것처럼 명령이 아닌 준비는 짧은 Python 조각으로 대신합니다.
